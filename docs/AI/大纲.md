# AI 全体系（完整版）

## 1 大语言模型（LLM）基础

- **LLM 原理**：Transformer 架构、自注意力机制、预训练+微调、上下文窗口
- **主流模型**：GPT-4o、Claude 3.5、DeepSeek-V3、Qwen2.5、Llama 3、Gemini 2.0
- **模型选型**：闭源 vs 开源、性能/成本权衡、多模态能力、上下文长度
- **Prompt Engineering**：零样本、少样本、思维链（CoT）、提示模板设计、结构化输出
- **模型调用**：OpenAI API、Anthropic API、国内云厂商 SDK（阿里/百度/腾讯/智谱）

### 模型微调与部署（新增）
- 参数高效微调（LoRA、QLoRA）
- 量化部署（GGUF、GPTQ）
- 本地模型运行（Ollama、llama.cpp、vLLM）

## 2 向量数据库与 RAG

- **向量检索原理**：Embedding 模型、相似度计算（余弦/欧氏）、HNSW 索引
- **主流向量数据库**：Pinecone、Qdrant、Milvus、Weaviate、Chroma、PGVector
- **RAG 架构**：检索增强生成、知识库构建、重排序、检索优化
- **Embedding 模型**：OpenAI text-embedding-3、BGE、M3E、智谱 Embedding
- **实践框架**：LangChain、LlamaIndex 中的 RAG 组件

### AI 数据准备与管理（新增）
- 数据清洗与预处理（非结构化文档解析）
- 数据标注平台（Label Studio、Prodigy）
- 知识库管理（分块策略、元数据、版本管理）

## 3 AI 应用开发框架与平台

- **Dify**：开源 LLM 应用开发平台
  - 核心功能：可视化工作流编排、内置 RAG、多模型接入、API 发布、日志监控
  - 部署方式：Docker 一键部署、云版、本地版
  - 与 LangChain 对比（低代码 vs 代码灵活性）
- **LangChain（Python/JS）**：组件化、Chain、Agent、工具集成
- **LlamaIndex**：专注数据索引与检索，构建复杂 RAG
- **Flowise**：低代码 LLM 应用构建工具（节点式编排）

### AI 工作流编排深度（新增）
- LangGraph（基于图的工作流，支持循环与状态）
- Dify 工作流高级模式（条件分支、并行、迭代）
- 低代码平台中的 AI 集成（n8n AI 节点、Zapier AI）

## 4 Agent 智能体

- **Agent 核心概念**：自主决策、工具调用、记忆管理、规划能力
- **ReAct 框架**：Reasoning + Acting，思维链与行动交替
- **工具定义**：Function Calling、自定义插件、多模态工具
- **多 Agent 协作**：AutoGen、CrewAI、MetaGPT
- **Agent 框架**：LangChain Agent、LlamaIndex Agent、AutoGPT
- **前端 Agent**：浏览器自动化、与前端交互的智能助手

### Agent 进阶（新增）
- 记忆管理（短期/长期、向量记忆）
- Agent 评估与调试
- 人机协同（确认机制、人工接管）

## 5 前端 AI 集成与 SDK

- **Vercel AI SDK（React/Vue/Svelte）**：流式聊天组件、Hook、生成 UI
- **Transformers.js**：浏览器内运行 Hugging Face 模型（文本分类、翻译、问答）
- **MediaPipe**：端侧视觉/语音识别（人脸检测、手势识别）
- **TensorFlow.js**：前端机器学习模型推理
- **AI 组件库**：聊天界面、代码编辑器、语音输入等现成组件

### 多模态 AI 前端集成（新增）
- 图像生成 API 调用与流式展示（Stable Diffusion、DALL·E）
- 语音识别与合成（Web Speech API、Whisper 前端封装）
- 视频分析（TensorFlow.js 视频流处理）

### AI 交互设计原则（新增）
- 会话式 UI、Copilot 模式
- 用户信任与可解释性（置信度展示、解释性输出）
- 人机协同交互模式

- **GitHub Copilot / Codeium**：插件式 AI 编程助手
- **AI 代码审查**：自动检测潜在 bug、安全漏洞、性能问题
- **AI 生成测试**：单元测试、E2E 测试脚本自动生成
- **AI 辅助调试**：错误分析、修复建议

## 8 AI 工程化与运维（原 AI 运维与监控，大幅扩展）

- **模型版本管理与实验追踪**：MLflow、Weights & Biases、DVC
- **模型部署与推理优化**：vLLM、TGI、ONNX Runtime、TensorRT
- **AI 网关与路由**：OpenRouter、LiteLLM（统一多模型接口、降级、负载均衡）
- **提示词版本管理与 A/B 测试**：LangSmith、自研平台
- **LLM 缓存策略**：Redis + 语义缓存，减少重复调用成本
- **成本监控与资产化**：Token 用量统计、预算告警、模型成本对比、ROI 分析
- **输出质量评估**：自动评估（BLEU、ROUGE）、LLM-as-a-judge、人工反馈（RLHF）
- **可观测性**：LangSmith、Arize、Helicone（追踪、监控、调试）
