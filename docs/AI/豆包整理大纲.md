# AI 全体系（完整版・整合补充・最终定稿）

适用于面试 / 复习 / 知识体系梳理，内容覆盖 LLM、RAG、Agent、前端 AI、工程化、安全、产品全链路

## 1 大语言模型（LLM）基础

### LLM 原理
- **核心架构**：Transformer 架构、Decoder-only（GPT 系）与 Encoder-Decoder（T5 系）
- **核心机制**：自注意力机制 / 多头注意力、下一个词预测（Next Token Prediction）
- **训练范式**：预训练 → 监督微调 SFT → 对齐训练（DPO / PPO / KTO）
- **关键配置**：上下文窗口、温度 temperature、top_p、top_k、频率惩罚、存在惩罚
- **长文本技术**：ROPE 动态插值、滑动窗口、LongLora、上下文重压缩

### 主流模型
- **闭源**：GPT-4o、Claude 3.5、Gemini 2.0
- **开源**：Llama 3、Qwen2.5、DeepSeek-V3、ChatGLM、InternLM、Baichuan
- **多模态模型**：统一文本 + 图像 + 音频建模能力

### 模型选型
- 闭源 vs 开源、性能 / 成本 / 速度权衡
- 多模态能力、上下文长度、推理速度、合规性

### Prompt Engineering
- 零样本 / 少样本学习
- 思维链 CoT、自我一致性 Self-Consistency
- 提示模板设计、角色设定、约束式指令
- 结构化输出：JSON Mode、JSON Schema、Function Calling 规范

### 模型调用
- OpenAI API、Anthropic API
- 国内厂商：阿里通义、百度文心、腾讯混元、智谱 GLM 等 SDK
- 统一调用封装：兼容 OpenAI 格式的代理层

### 模型微调与部署
- **参数高效微调**：LoRA、QLoRA、全量微调
- **量化技术**：INT4/INT8/FP8/AWQ/GGUF/GPTQ
- **本地推理**：Ollama、llama.cpp、vLLM、TGI
- **推理优化**：推测解码 Speculative Sampling、连续批处理、动态批处理

## 2 向量数据库与 RAG

### 向量检索原理
- Embedding 文本向量化
- 相似度计算：余弦相似度、欧氏距离、点积（内积）
- 索引结构：HNSW、IVF、Flat、SCANN、DiskANN

### 主流向量数据库
- Pinecone、Qdrant、Milvus、Weaviate、Chroma、PGVector
- 选型维度：内存 / 磁盘存储、分布式、元数据过滤、开源 / 闭源

### RAG 架构（检索增强生成）
- **标准流程**：文档加载 → 解析 → 分块 Chunking → Embedding → 入库 → 检索 → 重排 → 生成
- **基础 RAG、Hybrid Search 混合检索**（向量 + BM25 关键词）
- **高级 RAG**：Multi-Query 多查询检索、Parent-Document 检索、RAG-Fusion、Self-RAG、Corrective-RAG
- **重排序 Rerank**：bge-reranker、Cohere Rerank 等模型
- **KG-RAG**：知识图谱 + 向量检索融合

### Embedding 模型
- OpenAI text-embedding-3
- 开源：BGE、M3E、GTE
- 国内：智谱 Embedding、阿里 Embedding 等

### AI 数据准备与管理
- 非结构化文档解析：PDF/Word/Markdown/ 网页抽取
- 分块策略：按句子、按语义、按 Markdown 层级、递归分块
- 数据标注平台：Label Studio、Prodigy
- 知识库管理：元数据过滤、版本管理、去重、增量更新
