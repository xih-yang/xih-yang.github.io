## API Dash
API Dash 是一个使用 Flutter 构建的漂亮且开源的跨平台 API 客户端，它可以轻松创建和自定义 API 请求，可视化检查响应并生成 API 集成代码。它支持 macOS、Windows、Linux、Android 和 iOS 系统，是 Postman 和 Insomnia 的一个轻量级替代方案。
