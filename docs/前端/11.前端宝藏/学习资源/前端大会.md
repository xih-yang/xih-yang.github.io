# 前端大会

当今，前端技术的发展日新月异，为了跟上这个快速变化的行业步伐，许多国内外的前端技术大会应运而生。这些大会不仅为开发者们提供了一个交流和学习的平台，同时也展示了前端领域最新的趋势和创新。无论是沉浸在国外顶尖大会的氛围中，还是参加国内精彩的技术盛宴，都能够汲取前沿的知识，探索前端世界的边界。本文将带你一起探索国内外一些备受瞩目的前端技术大会，领略全球前端技术的风采。

## 国内前端大会
### GMTC 全球大前端技术大会
GMTC 全球大前端技术大会是由极客邦科技旗下 InfoQ 中国主办的顶级技术盛会，关注移动、前端、AI应用等多个技术领域，促进全球技术交流，推动国内技术升级。GMTC为期2天，主要面向各行业对移动开发、前端、AI技术感兴趣的中高端技术人员，大会聚焦前沿技术及实践经验，旨在帮助参会者了解大前端&移动开发领域最新的技术趋势与最佳实践。



+ 官网：[https://gmtc.infoq.cn/](https://gmtc.infoq.cn/)
+ 时间：每年举办一次，每次时间不一样，以官网为准。最近一次为 2023.2.6-2.7。

### D2 终端技术大会
D2 终端技术大会 (Mobile Developer & Frontend Developer Technology Conference, 简称 D2）是由阿里巴巴终端技术委员会主办，面向全球终端开发领域，立志于促进业内交流、引领终端领域发展的技术大会。



大会每年聚焦的方向都有所不同，2022年**聚焦「前端」和「客户端」两大终端技术方向**，不仅会重视内容的深度，同时也会拓宽内容的广度，希望和大家一起了解一线互联网在前端/客户端领域的技术探索与未来。



+ 官网：[https://d2.alibabatech.com/](https://d2.alibabatech.com/)
+ 时间：每年举办一次，每次时间不一样，以官网为准。最近一次为 2022.12.17-12.18。

### 稀土开发者大会
稀土开发者大会是由稀土掘金技术社区主办，集国际化前瞻性及实践性为一体的综合性技术大会。第三届稀土开发者大会（XDC 2023）将于 06.30-07.01 在北京举行，大会主题为「代码不止，掘金不停」，议题涵盖大前端、云原生、架构、大模型与 AIGC、研发效能、音视频、出海等多个方向，旨在帮助开发者拓宽技术视野，传播前沿的技术理念，共创开发者的技术盛会。



官网：[https://conf.juejin.cn/](https://conf.juejin.cn/)

时间：每年举办一次，每次时间不一样，以官网为准。最近一次为 2023.6.30-7.1。

### 前端早早聊大会
前端早早聊是面向前端工程师的技术社区，如旗下的前端早早聊大会涵盖管理、可视化、跨端、监控、框架、构建...等诸多话题，讲师来自阿里、腾讯、字节、百度等各大厂，内容接地气，是前端工程师跟进学习的优质平台，是前端主管带领团队，以及前端培训可以参考的百科全书。早早聊大会每个月至少举办一期，目前已经举办了 67 期。



+ 官网：[https://www.zaozao.run/](https://www.zaozao.run/)
+ 时间：每个月至少举办一期。

### VueConf
中国最大的 Vuejs 大会，由前端圈主办，前端圈社区自成立以来受到了W3C等组织、公司和大家的大力支持与帮助，一直在为Web前端开发者提供技术分享和交流的平台，促进全球技术交流，推动国内技术升级，打造前端专业技术会议，打造一个良好的前端圈生态，推动Web标准化的发展。



+ 官网：[https://node.fequan.com/](https://node.fequan.com/)
+ 时间：最近一次举办为 2022-12-10。2023 年的 VueConf 因为某些原因已取消。

### Vue Conf Taiwan
Vue.js Taiwan 社群自 2015 年由几位热爱Vue.js 的朋友共同创立，期望透过线上与线下社群的平台，提供对于Vue.js 相关议题、专案、技术以及工作的朋友们进行分享与交流。今年再度延续前届的热情，与 Laravel 台湾社群合作，共同举办了 {Laravel x Vue} Conf Taiwan 2023。今年的大会邀请了Vue创建者尤雨溪出席。



+ 官网：[https://laravelconf.tw/](https://laravelconf.tw/)
+ 时间：最近一次举办为 2023-8-19。

### Web 前沿技术论坛
由 W3C 中国组织，将深入探讨最新的 Web 技术及发展趋势，重点关注 **Web 安全、智能应用、多媒体、分布式身份、云与 Web 交互**等前沿技术并围绕相关技术的**国际化与无障碍**特性展开探讨。通过技术分享及经验交流，共同探索如何应对当今 Web 面临的挑战，发掘解决方案，进一步满足行业及用户需求。



+ 官网：[https://www.w3.org/2023/06/china-web-forum/](https://www.w3.org/2023/06/china-web-forum/)
+ 时间：最近一次举办为 2023-6-19。

## 国外前端大会
### JSWorld
世界上最大的JavaScript 会议，会议旨在为JavaScript开发者提供一个交流和学习的平台，涵盖了JavaScript的各个方面，包括框架、库、工具和最佳实践等。会议邀请了来自业界知名公司和组织的演讲嘉宾，分享他们的经验和见解。这是一个与来自 Vue、Astro、Nuxt、Angular、Vite 和 Storybook 的创建者和维护者取得联系的绝佳机会。您将获得有关最大和最热门技术的技术更新以及有关如何应对开发人员挑战的案例研究。



2024 年 2 月与 2500 名 JavaScript 开发人员一起参加为期 3 天的 JavaScript 庆典**。**包含作者、创作者和专家的最新 JavaScript 更新。75 场演讲展示了涉及 TypeScript、Node.js、React、Vue、Angular、Qwik、Vite、AuthZ 和 gRPC 等最新主题。



+ 官网：[https://jsworldconference.com/](https://jsworldconference.com/)
+ 时间：每年举办一次，每次时间不一样，以官网为准。最近一次为 **2024.2.28**。

### VueJS Amsterdam
Vuejs 阿姆斯特丹会议是世界上最特别、规模最大的 Vue 会议，共有来自世界 50 多个国家、437 家公司的 1,100 人参加。Vuejs 阿姆斯特丹是年度 Vue 社区活动。**Vuejs 阿姆斯特丹 2024 将于 2024 年 2 月在阿姆斯特丹剧院举行。**与会者可以与创作者、维护者和专业人士会面、问候和交谈，同时建立终生的联系并获得终生难忘的体验。



+ 官网：[https://vuejs.amsterdam/](https://vuejs.amsterdam/)
+ 时间：每年举办一次，每次时间不一样，以官网为准。最近一次为 **2024.2.28**。

### VueConf US
VueConf US 是 Vue.js 社区组织的一次年度性质的会议，会议由 Vue.js 的创建者和核心团队主持，旨在聚集全球的 Vue.js 开发者和爱好者，分享关于 Vue.js 的最新技术、最佳实践和行业经验。会议在美国举办，是 Vue.js 生态系统中最大规模的国际会议之一。会议邀请了来自各个领域的 Vue.js 技术专家和行业领袖，他们将进行主题演讲、工作坊和研讨会，分享他们在 Vue.js 开发方面的见解和经验。



+ 官网：[https://us.vuejs.org/](https://us.vuejs.org/)
+ 时间：每年举办一次，每次时间不一样，以官网为准。最近一次为 **2023.5.24**。

### React Summit
React Summit 是一个面向 React 开发者和社区的年度技术峰会，是**全球最大的 REACT 会议。**旨在分享 React 相关的最新技术、最佳实践和行业动态。会议汇集了全球范围内的 React 开发者、工程师和专家，提供了一个学习、交流和分享的平台。在峰会上，参会者可以聆听来自知名公司、组织和社区的演讲嘉宾分享他们在 React 领域的经验、洞见和创新。



+ 官网：[https://reactsummit.com/](https://reactsummit.com/)、[https://reactsummit.us/](https://reactsummit.us/)
+ 时间：每年举办，每次时间不一样，以官网为准。最近一次为 **2023.5.24，**美国分会将于 2023.11.13 举行。

### React Live
与 500 名 React 开发人员一起参加一整天的 React 庆典**。**包含作者、创作者和专家的最新 React (18) 更新。讲座深入探讨 Next.js、React 18、抽象语法树、带有 WASM 的 React 应用、服务端组件、Edge 等最新主题！将获得有关最大和最热门技术的技术更新，以及有关如何解决开发人员挑战的案例研究，同时与阿姆斯特丹的 React 社区保持联系。



+ 官网：[https://reactlive.nl/](https://reactlive.nl/)
+ 时间：每年举办一次，每次时间不一样，以官网为准。最近一次为 2023.9.29。

### DEV WORLD
全球排名第一的开发者大会，提供了直接与 7500 名开发人员面对面交流以及另外 2500 名在线观众的独特机会。2024 年的会议将带来 200 个独特的演讲，涵盖 JavaScript、后端、全栈、AI - ChatGPT、DevOps 和云等方面。



+ 官网：[https://devworldconference.com/](https://devworldconference.com/)
+ 时间：每年举办一次，每次时间不一样，以官网为准。最近一次为 2024.2.29。

### Vite Conf
_ViteConf_ 是一个沉浸式互动在线活动，面向前端团队，利用 Vite 构建下一代网络。通过该会议了解前端团队如何使用 Vite 构建下一代网络。聆听最流行的前端工具的创建者的演讲，与其他社区成员联系并与演示者实时聊天，可以在观看时深入了解交互式代码示例。



+ 官网：[https://viteconf.org/23/](https://viteconf.org/23/)
+ 时间：每年举办一次，每次时间不一样，以官网为准。最近一次为 2023.10.5。

### CSS Day
CSS Day 始于 2013 年，是一个为期一天、重点突出的高级 CSS 会议，与会者和演讲者包括 CSS 设计师、开发人员、规范编写者和浏览器供应商。会议气氛轻松，有充足的休息时间，每个人都可以互相接触。



+ 官网：[https://cssday.nl/2023](https://cssday.nl/2023)
+ 时间：每年举办一次，每次时间不一样，以官网为准。最近一次为 2024.6.8。

### ReactNext

+ 官网：[https://www.react-next.com/](https://www.react-next.com/)
+ 时间：每年举办一次，每次时间不一样，以官网为准。最近一次为 2024.6.24。

### JSHeroes
JSHeroes 是一个非营利性社区组织的会议，每年在罗马尼亚克卢日举行。会议的目标是将来自世界各地的 JS 和 Web/前端开发爱好者聚集在一起，参加为期两天的活动：精彩的演讲、令人惊叹的网络和大量的乐趣。



+ 官网：[https://jsheroes.io/](https://jsheroes.io/)
