# 画图工具

下常用的画图工具：

+ **常规画图：**Excalidraw、draw.io、语雀
+ **思维导图：**Xmind
+ **代码截图：**Carbon
+ **画图模板：**ProcessOn

## Excalidraw
Excalidraw 是一款轻量、开源的手绘风格电子白板和画图应用，可以快速画出漂亮的流程图、UML图甚至是图表。

![1666444424698-643743b1-23cf-4662-a0de-b9ebc2f2193b.png](./img/rHZDwmTLDu39JP0h/1666444424698-643743b1-23cf-4662-a0de-b9ebc2f2193b-544242.png)

Excalidraw 提供了丰富的素材库，包含手绘风格的图标、图标等：

![1666444808730-823dd106-64bb-4df7-bcd2-6cc37f06e53d.png](./img/rHZDwmTLDu39JP0h/1666444808730-823dd106-64bb-4df7-bcd2-6cc37f06e53d-140411.png)

可以在模版市场来搜索需要的模板组件：

![1666444864213-f7eaf57a-d859-4f77-bfac-64b9e80d7080.png](./img/rHZDwmTLDu39JP0h/1666444864213-f7eaf57a-d859-4f77-bfac-64b9e80d7080-962188.png)

除此之外，Excalidraw 还有很多特点：

+ 界面简洁，模版众多，支持键盘快捷键，可以快速上手；
+ 免注册，支持切换为中文语言；
+ 内容安全，采用端到端加密，不会将内容上传到云端；
+ 支持导出图片、导出源文件、分享链接、实时协作、将内容保存到工作区。



**在线地址：**[https://excalidraw.com/](https://excalidraw.com/)

## Draw.io
draw.io 是一款免费的在线图表编辑工具，<font style="color:rgb(77, 77, 77);">可以绘制流程图、UML、类图、组织结构图、</font>泳道图<font style="color:rgb(77, 77, 77);">、E-R图、思维导图等，</font>堪称画图神器！

![1666445361599-23b08c81-969f-44f9-ae43-a1dd344e7454.png](./img/rHZDwmTLDu39JP0h/1666445361599-23b08c81-969f-44f9-ae43-a1dd344e7454-232123.png)

draw.io 提供了丰富的模版，<font style="color:rgba(0, 0, 0, 0.75);">支持商务、图表、cloud、工程、流程图、布局、地图、网络、软件、表格、UML、Venn等。还可以自定义模板。</font>

![1666446709009-0d165aa8-de43-4fd6-97b7-e2223b4cb1a7.png](./img/rHZDwmTLDu39JP0h/1666446709009-0d165aa8-de43-4fd6-97b7-e2223b4cb1a7-594558.png)

除此之外，Draw.io 还有很多特点：

+ 支持语言设置为中文；
+ 支持使用图层；
+ 支持设置手绘风格、自带多种图标，支持自定义图标；
+ 支持将图片导出为PNG、JEPG、SVG、PDF、HTML、XML等，支持导出高级设置，如调整DPI、宽高、缩放、背景等。



+ **<font style="color:rgb(77, 77, 77);">在线地址：</font>**<font style="color:rgb(77, 77, 77);">https://app.diagrams.net/</font>
+ **<font style="color:rgb(77, 77, 77);">下载地址：</font>**<font style="color:rgb(77, 77, 77);">https://github.com/jgraph/drawio/releases</font>

## 语雀
语雀是一款面向未来的文档和知识协同工具，可以用来记笔记，也可以用来画图。语雀画板支持基础图形、流程图、UML图、ER图、思维导图等。

![1666447273385-b1222707-5a49-4716-8f0a-7e6c2e1f9a59.png](./img/rHZDwmTLDu39JP0h/1666447273385-b1222707-5a49-4716-8f0a-7e6c2e1f9a59-194940.png)

语雀画板还支持直接从 icofont 搜索、添加图标：

![1666447408105-10cab3ec-3c4e-4db4-ba79-deb502fe689f.png](./img/rHZDwmTLDu39JP0h/1666447408105-10cab3ec-3c4e-4db4-ba79-deb502fe689f-042072.png)

其还提供了一些常用图的模版：

![1666447488450-91e88a10-4410-44f0-8003-0ddee85190c1.png](./img/rHZDwmTLDu39JP0h/1666447488450-91e88a10-4410-44f0-8003-0ddee85190c1-559520.png)

除此之外，语雀画板还有以下特点：

+ 支持团队协作绘图；
+ 保存版本，恢复历史版本。



+ **常用模板：**[https://www.yuque.com/danchun-eekrs/pbxiht](https://www.yuque.com/danchun-eekrs/pbxiht)
+ **在线地址：**[https://www.yuque.com/](https://www.yuque.com/)

## Xmind
<font style="color:rgb(51, 51, 51);">XMind 是一个跨平台的思维导图软件，</font><font style="color:rgb(51, 51, 51);">具有多种结构样式，除了普通的思维导图，还包括树形图、逻辑图、鱼骨图、时间轴、树状表格等等，不同的结构样式可以自由组合混用，同时支持一键更换结构样式。</font>

![1666448672529-b5fd802f-6bde-46a4-9a3c-92909b5608b0.png](./img/rHZDwmTLDu39JP0h/1666448672529-b5fd802f-6bde-46a4-9a3c-92909b5608b0-018989.png)

Xmind 提供了很多类型的思维导图，并支持设置多种主题风格：

![1666448779537-73e33e78-f14e-4a99-87c1-b11488c33fd4.png](./img/rHZDwmTLDu39JP0h/1666448779537-73e33e78-f14e-4a99-87c1-b11488c33fd4-185950.png)

除此之外，Xmind 还有很多特点：

+ <font style="color:rgb(51, 51, 51);">可以灵活的定制节点外观、插入图标外，还有多种样式、主题色彩、贴图可以选择，主题颜色和样式同样支持自由组合；</font>
+ <font style="color:rgb(51, 51, 51);">除了 XMind 自身的格式，还支持导入 FreeMind、MindManager 等软件的文件格式，支持导出PNG、SVG、PDF、Markdown、Word、Excel 等；</font>
+ <font style="color:rgb(51, 51, 51);">支持进行动态演示。</font>

<font style="color:rgb(51, 51, 51);"></font>

**<font style="color:rgb(51, 51, 51);">下载地址：</font>**[https://xmind.app/download/](https://xmind.app/download/)

## Carbon
<font style="color:rgb(18, 18, 18);">Carbon是开源免费的代码图片生成器，可以快速生成漂亮的代码图片。操作简单，直接将代码粘贴在代码区，设置想要的格式即可。</font>

![1666448111812-f9cfc0b9-0878-4402-adf8-3e3fa778f8fa.png](./img/rHZDwmTLDu39JP0h/1666448111812-f9cfc0b9-0878-4402-adf8-3e3fa778f8fa-352338.png)

生成的代码图片非常适合用来分享：

![1666448320001-05adc845-78f3-4fb4-b078-f351ed99fcf5.png](./img/rHZDwmTLDu39JP0h/1666448320001-05adc845-78f3-4fb4-b078-f351ed99fcf5-619532.png)

除此之外，Carbbon 还有很多特点：

+ 支持多种代码风格、支持自定义代码风格，支持主流的各种编程语言；
+ 支持设置代码的字体、行号、行数等文本格式；
+ 支持设置图片的边距、背景、颜色、阴影、大小等。



**在线地址：**[https://carbon.now.sh/](https://carbon.now.sh/)

## ProcessOn
ProcessOn 是一个在线协作绘图平台，支持在线制作思维导图、流程图、组织结构图、网络拓扑图、鱼骨图、UML图等。不过其免费版只支持添加 9 张图。所以这里主要推荐其丰富的模版市场，可以通过分类、关键字搜索来查找合适的模版：：

![1666449685244-d2642a06-60ac-408a-81ce-e973d58dd1e1.png](./img/rHZDwmTLDu39JP0h/1666449685244-d2642a06-60ac-408a-81ce-e973d58dd1e1-942061.png)

这些模版可以为我们提供一些绘图思路，可以根据这些图来绘制想要的图：

![1666449791925-69813002-5e07-4011-a0bf-aad619dcf7e3.png](./img/rHZDwmTLDu39JP0h/1666449791925-69813002-5e07-4011-a0bf-aad619dcf7e3-029817.png)
