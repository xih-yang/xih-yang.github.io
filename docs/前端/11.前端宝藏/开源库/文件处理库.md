## 1. PDF
### （1）PDF.js
PDF.js是使用 HTML5 构建的可移植文档格式 (PDF) 查看器。它由社区驱动并受 Mozilla 支持，目标是创建一个通用的、基于 Web 标准的平台来解析和呈现 PDF。

![1657462054009-7480ac84-c28e-4909-8bc9-b68eb38206ad.png](./img/LgEi0ukTsdfKLiqY/1657462054009-7480ac84-c28e-4909-8bc9-b68eb38206ad-812439.png)

**Github（****⭐****️ 39.2k）：**[https://github.com/mozilla/pdf.js](https://github.com/mozilla/pdf.js)

### （2）jsPDF
jsPDF 是一个使用 JavaScript 语言生成 PDF 的开源库，是一个用于生成 PDF 的领先的 HTML5 客户端解决方案。

![1657462911906-fe4483d1-dde4-416b-b7f0-4cb6b69c4b41.png](./img/LgEi0ukTsdfKLiqY/1657462911906-fe4483d1-dde4-416b-b7f0-4cb6b69c4b41-763703.png)

**Github（****⭐****️ 24.6k）：**[https://github.com/parallax/jsPDF](https://github.com/parallax/jsPDF)

### （3）pdfmake
在纯 JavaScript 中用于服务器端和客户端的 PDF 文档生成库。

![1657463503527-9a884951-1607-41ab-abb2-d2e771d67685.png](./img/LgEi0ukTsdfKLiqY/1657463503527-9a884951-1607-41ab-abb2-d2e771d67685-278115.png)

**Github（****⭐****️ 10.2k）：**[https://github.com/bpampuch/pdfmake](https://github.com/bpampuch/pdfmake)

### （4）pdf-lib
pdf-lib 可以在任何 JavaScript 环境中创建和修改 PDF 文档。它旨在解决 JavaScript 生态系统对 PDF 操作（尤其是 PDF修改）缺乏强大支持的问题。可以用于任何现代 JavaScript 运行时，如 Node、Browser、Deno 和 React Native 等。

![1657464689492-3b177db2-cee9-41d6-8ffc-8bd2b44a2cd1.png](./img/LgEi0ukTsdfKLiqY/1657464689492-3b177db2-cee9-41d6-8ffc-8bd2b44a2cd1-480365.png)

**Github（****⭐****️ 4.1k）：**[https://github.com/Hopding/pdf-lib](https://github.com/Hopding/pdf-lib)

### （5）**pdfkit**
PDFKit 是一个用于 Node 和浏览器的 PDF 文档生成库，可以轻松创建复杂的多页可打印文档。API 包含可链接性，并包括低级功能以及更高级别功能的抽象。PDFKit API 的设计很简单，因此生成复杂的文档通常只需几个函数调用即可。

![1657466430038-5ca36f4e-4545-4170-ac1c-444ec2a64178.png](./img/LgEi0ukTsdfKLiqY/1657466430038-5ca36f4e-4545-4170-ac1c-444ec2a64178-959317.png)

**Github（****⭐****️ 8.2k）：**[https://github.com/foliojs/pdfkit](https://github.com/foliojs/pdfkit)

### （6）**react-pdf**
react-pdf 是一个用于在浏览器和服务器上创建 PDF 文件的 React 渲染器。

![1657466736878-9b0118ac-e15c-4b26-b1ba-f0cb6a1acb17.png](./img/LgEi0ukTsdfKLiqY/1657466736878-9b0118ac-e15c-4b26-b1ba-f0cb6a1acb17-367049.png)

**Github（****⭐****️ 10.9k）：**[https://github.com/diegomura/react-pdf](https://github.com/diegomura/react-pdf)

## 2. 图片
### （1）sharp
sharp 是一个高性能的 Node.js 图像处理库，调整 JPEG、PNG、WebP、AVIF 和 TIFF 图像大小的最快模块。

![1657467735827-7527b2f3-8471-4c97-a84c-1900fd3ef594.png](./img/LgEi0ukTsdfKLiqY/1657467735827-7527b2f3-8471-4c97-a84c-1900fd3ef594-827997.png)

**Github（****⭐****️ 22.7k）：**[https://github.com/lovell/sharp](https://github.com/lovell/sharp)

### （2）cropperjs
cropperjs 是一个 JavaScript 图像裁剪器，支持29个裁剪选项、27种方法、6个事件、缩放、旋转等。

### （3）tui.image-editor
tui.image-editor 是一个使用 HTML5 Canvas 的全功能图像编辑器。它易于使用并提供强大的过滤器。

![1657470118701-f578d232-862e-4979-8f85-2127f5ed383e.png](./img/LgEi0ukTsdfKLiqY/1657470118701-f578d232-862e-4979-8f85-2127f5ed383e-402401.png)

**Github（****⭐****️ 5.2k）：**[https://github.com/nhn/tui.image-editor](https://github.com/nhn/tui.image-editor)

### （4）compressorjs
JavaScript 图像压缩器。使用浏览器原生的 canvas.toBlob API 来做压缩工作，即**有损压缩**，**异步**压缩，在不同的浏览器有**不同的压缩效果**。一般在客户端上传之前使用这个来预压缩图片。

### （5）**viewerjs**
viewerjs 是一个 JavaScript 图像查看器，支持52个查看选项、23种操作方法、17个事件、旋转、移动、缩放等。

## 3. 音视频
### （1）video.js
Video.js 是一个为 HTML5 世界从头开始构建的网络视频播放器。它支持 HTML5 视频和媒体源扩展，以及其他播放技术，如 YouTube 和 Vimeo（通过插件）。它支持在台式机和移动设备上播放视频。

![1657471942627-408eba4b-d082-471a-b3b4-f0efacb7f8cd.png](./img/LgEi0ukTsdfKLiqY/1657471942627-408eba4b-d082-471a-b3b4-f0efacb7f8cd-152379.png)

**Github（****⭐****️ 8.7k）：**[https://github.com/videojs/video.js](https://github.com/videojs/video.js)

### （2）plyr
Plyr 是一个简单、轻量级、可访问和可定制的 HTML5、YouTube 和 Vimeo 媒体播放器，支持现代浏览器。

![1657472049651-78b61867-72c5-4c3a-87ce-ec90030b6ea9.png](./img/LgEi0ukTsdfKLiqY/1657472049651-78b61867-72c5-4c3a-87ce-ec90030b6ea9-099648.png)

**Github（****⭐****️ 22.3k）：**[https://github.com/sampotts/plyr](https://github.com/sampotts/plyr)

### （3）MediaElement.js
MediaElement.js 是一个HTML5 <audio> 或 <video> 播放器，支持 MP4、WebM 和 MP3 以及 HLS、Dash、YouTube、Facebook、SoundCloud 等，具有通用 HTML5 MediaElement API，可在所有浏览器中实现一致的 UI。

![1657474380271-9f1985bd-8b0d-4c1e-835c-475e07e645ff.png](./img/LgEi0ukTsdfKLiqY/1657474380271-9f1985bd-8b0d-4c1e-835c-475e07e645ff-688446.png)

**Github（****⭐****️ 7.9k）：**[https://github.com/mediaelement/mediaelement](https://github.com/mediaelement/mediaelement)

### （4）xgplayer
西瓜播放器是一个Web视频播放器类库，它本着一切都是组件化的原则设计了独立可拆卸的 UI 组件。更重要的是它不只是在 UI 层有灵活的表现，在功能上也做了大胆的尝试：摆脱视频加载、缓冲、格式支持对 video 的依赖。尤其是在 mp4 点播上做了较大的努力，让本不支持流式播放的 mp4 能做到分段加载，这就意味着可以做到清晰度无缝切换、加载控制、节省视频流量。同时，它也集成了对 flv、hls、dash 的点播和直播支持。

![1657474785135-58850b84-8d64-4369-bec6-e8fad6a12324.png](./img/LgEi0ukTsdfKLiqY/1657474785135-58850b84-8d64-4369-bec6-e8fad6a12324-343070.png)

**Github（****⭐****️ 5.4k）：**[https://github.com/bytedance/xgplayer](https://github.com/bytedance/xgplayer)

### （5）DPlayer
DPlayer 是一款可爱的 HTML5 弹幕视频播放器，可帮助人们轻松构建视频和弹幕。

![1657475030777-0158c4ce-8b7f-47ec-8ced-c6b42c886561.png](./img/LgEi0ukTsdfKLiqY/1657475030777-0158c4ce-8b7f-47ec-8ced-c6b42c886561-013934.png)

**Github（****⭐****️ 12.9k）：**[https://github.com/DIYgod/DPlayer](https://github.com/DIYgod/DPlayer)

### （6）Howler.js
howler.js 是一个现代 web 音频库。它默认为Web Audio API并回退到HTML5 Audio。这使得在所有平台上使用 JavaScript 处理音频变得容易且可靠。
