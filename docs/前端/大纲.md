十、AI 全体系（完整版）
1. 大语言模型（LLM）基础
   LLM 原理：Transformer架构、自注意力机制、预训练+微调、上下文窗口

主流模型：GPT-4o、Claude 3.5、DeepSeek-V3、Qwen2.5、Llama 3

模型选型：闭源vs开源、性能/成本权衡、多模态能力

Prompt Engineering：零样本、少样本、思维链（CoT）、提示模板设计

模型调用：OpenAI API、Anthropic API、国内云厂商（阿里/百度/腾讯）SDK

2. 向量数据库与 RAG
   向量检索原理：Embedding模型、相似度计算（余弦/欧氏）、HNSW索引

主流向量数据库：Pinecone、Qdrant、Milvus、Weaviate、Chroma、PGVector

RAG 架构：检索增强生成、知识库构建、重排序、检索优化

Embedding 模型：OpenAI text-embedding-3、BGE、M3E、智谱Embedding

实践框架：LangChain、LlamaIndex 中的 RAG 组件

3. AI 应用开发框架与平台
   Dify：开源 LLM 应用开发平台（可视化工作流、内置RAG、多模型接入）

核心功能：工作流编排、知识库管理、API发布、日志监控

部署方式：Docker 一键部署、云版、本地版

与 LangChain 对比：低代码 vs 代码灵活性

LangChain：Python/JS 链式调用框架（组件化、Chain、Agent）

LlamaIndex：专注于数据索引与检索，适合构建复杂RAG

Flowise：低代码 LLM 应用构建工具（节点式编排）

4. Agent 智能体
   Agent 核心概念：自主决策、工具调用、记忆管理

ReAct 框架：Reasoning + Acting，思维链与行动交替

工具定义：Function Calling、自定义插件、多模态工具

多 Agent 协作：AutoGen、CrewAI、MetaGPT

Agent 框架：LangChain Agent、LlamaIndex Agent、AutoGPT

前端 Agent：浏览器自动化、与前端交互的智能助手
