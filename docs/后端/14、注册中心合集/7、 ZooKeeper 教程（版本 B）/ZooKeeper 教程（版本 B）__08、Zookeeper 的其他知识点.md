## 1. Zookeeper的选举机制

## 1.1. 选举机制概述

半数机制，超过半数的投票通过，即通过。

## 1.2. 第一次启动选举规则

投票过半数时，服务器 id 大的胜出

## 1.3. 第二次启动选举规则

> ①EPOCH 大的直接胜出
>
> ②EPOCH 相同，事务 id 大的胜出
>
> ③事务 id 相同，服务器 id 大的胜出

## 2. 在大数据集群中Zookeeper的台数

首先确定是要安装奇数台

然后服务器台数多：好处，提高可靠性；坏处：提高通信延时

一般建议如下：

- 10 台服务器：3 台 zk；
- 20 台服务器：5 台 zk；
- 100 台服务器：11 台 zk；
- 200 台服务器：11 台 zk；

## 3. Zookeeper中的常用命令

ls：获取该节点下所有的子节点

get：获取该节点的数据

create：创建节点

delete：删除指定节点

可以在zookeeper客户端中通过 help 命令查看对应的操作命令
