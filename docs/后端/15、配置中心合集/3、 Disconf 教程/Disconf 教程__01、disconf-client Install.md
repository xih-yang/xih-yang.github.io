# 01、disconf-client Install
- 来源：https://ddkk.com/zhuanlan/config/disconf/1.html
- 分类：配置中心
- 分组：Disconf 教程
在您的Maven POM 文件里加入：

```xml
<dependency>
    <groupId>com.baidu.disconf</groupId>
    <artifactId>disconf-client</artifactId>
    <version>2.6.36</version>
</dependency>
```
