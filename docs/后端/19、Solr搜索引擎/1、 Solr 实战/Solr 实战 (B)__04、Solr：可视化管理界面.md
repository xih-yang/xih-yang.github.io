# 04、Solr：可视化管理界面
- 来源：https://ddkk.com/zhuanlan/search/solr/2/18.html
- 分类：搜索引擎
- 分组：Solr 实战 (B)
在关闭防火墙的前提下，可以在 windows 的浏览器中访问 Solr。

输入: http://IP:8983 （http://192.168.32.133:8983 ）就可以访问 Solr 的可视化管理界面。

左侧有 5 个菜单。分别是：

（1）Dashboard：面板显示 Solr 的总体信息。

（2）Logging：日志

（3）Core Admin：Solr 的核心。类似于数据的 Database

（4）Java Perperties：所有 Java 相关属性

（5）Thread Dump：线程相关信息。

（6）如果有 Core，将显示在此处。
