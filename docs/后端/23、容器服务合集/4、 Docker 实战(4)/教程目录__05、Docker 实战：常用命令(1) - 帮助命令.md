### 帮助命令

```java
[root@ddkk.com ~]# docker version           显示docker的版本信息
```

```java
[root@ddkk.com ~]# docker info              显示docker的系统信息，包括镜像和容器的数量
```

```java
[root@ddkk.com ~]# docker 命令 --help        帮助命令
```
