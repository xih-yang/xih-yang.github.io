## 客户端集成

CAT推出多种语言的客户端，基本覆盖了主流开发语言。

CAT目前支持：：Java、C、Python、node、Go等语言的接入。详情请参考：[传送门](https://github.com/dianping/cat/tree/master/lib)

注意所有的客户端均在lib目录下，Java客户端也是，Java客户端不再使用cat-client这个模块，这个客户端无任何依赖。

- Java
- C
- C++
- Python
- Go
- Node.js

其它语言客户端接入：

- .NET 客户端

项目地址 [ctripcorp/cat.net](https://github.com/ctripcorp/cat.net)，携程提供。
