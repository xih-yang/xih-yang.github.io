# 06、Intellij Idea 窗口元素
- 来源：https://ddkk.com/zhuanlan/tools/idea/6.html
- 分类：开发工具
- 分组：教程目录
为了提高 IntelliJ IDE 的性能，我们需要了解和识别编辑器主窗口中存在的视觉元素。以下屏幕截图显示了 IntelliJ 主编辑器窗口。

主窗口可分为以下部分：

### 1. 菜单栏

主菜单栏提供了我们可以用来执行诸如创建新项目、管理文件、重构代码、构建、运行、调试选项等任务的选项。

### 2. 工具栏

工具栏包含执行一些操作的快捷选项，如编译、调试、运行等。我们也可以根据需要自定义这个工具栏。

### 3. 导航栏

这个栏是一个快速而好的替代方法，可以轻松快速地浏览项目文件。

### 4. 工具选项卡

它显示在屏幕的两侧和 IntelliJ IDE 的底部。在这里，我们可以直接访问一些工具，例如 Databases、Maven Projects、Ant Builds 等。

### 5. 项目结构

它显示了项目的各种元素，如包、类、模块、工作区、库等。

### 6. 编辑器窗口

编辑器是我们可以编写代码的地方。在这里，开发人员大部分时间都在根据项目的需求开发代码。

### 7. 状态栏

状态栏显示有关当前打开的文件和当前项目状态的信息。它还提供了有关最近项目汇编的信息。我们可以在编辑器窗口底部显示状态栏。
