# 07、Intellij Idea 代码编辑器元素
- 来源：https://ddkk.com/zhuanlan/tools/idea/7.html
- 分类：开发工具
- 分组：教程目录
代码编辑器提供了有助于在代码中导航并识别其问题的元素。本节讨论编辑器的视觉元素及其最常见的操作。在下面的截图中，我们可以看到编辑器是如何划分的：

### 1. 编辑区

这是开发人员花费大部分时间来实现其逻辑的主要区域，也可以稍后对其进行编辑。

### 2. Gutter区域

Gutter 区域是显示有关代码的不同类型信息的区域。它提供了一个选项来运行、调试和运行具有覆盖范围的应用程序。装订线区域显示以下信息

- 代码行号
- 断点
- 范围
- 相互指向的箭头表示方法的开始和结束位置。

### 3. 智能代码补全弹窗

智能代码完成弹出窗口根据代码的当前上下文为开发人员提供快速帮助。

### 4. 文档标签区

文档选项卡区域显示所有打开的文档选项卡。每个文档选项卡都有不同的含义，可以通过文件名称中的颜色来识别。这些颜色是蓝色表示“已修改”，绿色表示“新”，红色表示“不在 VCS”，黑色表示“未更改”。

### 5. 标记栏

标记栏显示代码的当前状态。它用不同的颜色突出显示代码的状态。该绿颜色表示的代码是OK，黄色是警告和红色是编译错误。

### 6. 浮动图标

- 第一个图标表示代码修改。它仅涵盖警告更正以改进我们的代码。不一定要修改我们的代码。
- 第二个图标仅表示意图操作。它不提供任何改进或代码修改。
- 第三个图标表示快速修复操作。它提供纠正一个显着的代码错误。
- 第四个图标表示警报操作。
