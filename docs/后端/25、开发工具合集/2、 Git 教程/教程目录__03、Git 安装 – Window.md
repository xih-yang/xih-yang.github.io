Git不是系统内置的软件，需要安装才能使用

Git是垮平台的，支持的系统有 Linux/Unix、Solaris、Mac和 Windows

Git各个平台的安装包下载地址为 [http://git-scm.com/downloads](http://git-scm.com/downloads)

## Windows 平台上安装 Git

Windows 上可以使用 msysgit 项目提供的安装包

msysgit 的官方地址为 [http://msysgit.github.io/](http://msysgit.github.io/)

> 很悲剧的一点，似乎受到某些不可抗击的原因，下载速度简直慢如蜗牛

我们可以选择合适的 CPU 版本，现在的 Window 电脑一般都是 64 位的

下载完成可以双击 Git-2.15.0-64-bit.exe 进行安装

msysgit 除了提供终端(命令行) 的 git 命令外，还提供了操作简单的 Git 图形界面

安装完成后可以在开始菜单里找到”Git”->”Git Bash”，会弹出 Git 命令窗口

接下来我们就可以在该窗口进行 Git 操作
