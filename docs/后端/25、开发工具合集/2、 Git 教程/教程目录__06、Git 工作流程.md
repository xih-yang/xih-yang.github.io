# 06、Git 工作流程
- 来源：https://ddkk.com/zhuanlan/tools/git/6.html
- 分类：开发工具
- 分组：教程目录
配置好了 Git，我们就可以来学习如何使用 Git 进行日常的开发

使用Git 日常开发的流程一般如下

**1、** 创建或克隆Git资源作为工作目录；

**2、** 在克隆的资源上添加或修改文件；

**3、** 如果其他人修改了，我们可以更新资源；

**4、** 在提交前查看修改；

**5、** 提交修改到本地；

**6、** 提交修改到远程；

**7、** 在修改完成后，如果发现错误，可以撤回提交并再次修改并提交；
