## sync(Synchronize)命令

一般个人使用电脑时保存会让数据保存到硬盘里，在服务器中有些时候访问的人数量比较多，硬盘传输速度比不上cpu处理速度，数据不能一次全部保存到硬盘里，所以一般会先保存在内存缓存区（buffer）中，sync命令可以让数据同步到硬盘中，关机或重启之前可以多执行几次sync命令。

作用：刷新文件系统缓存区，同步数据。

执行权限：所有用户。

## shutdown命令

作用：关机或重启。

执行权限：所有用户。

命令格式：shutdown [选项] 时间 [警告信息] #时间默认分钟作为单位

常用选项：

- -c：取消已经执行的shutdown命令。
- -h：关机。
- -r：重启。
- -t：秒作为单位。

**注：关机或重启建议使用shutdown命令，是最安全的关机重启命令。**

## reboot命令

作用：重启。

## halt和poweroff命令

作用：关机。

**注：这两个命令不会完整管理和保存系统的服务，不建议使用。**

## init命令

init命令是调用Linux系统级别的命令，这个命令也可以用来关机和重启，但不安全，不建议使用。

例：

```java
[root@ddkk.com ~]# init 0
#关机，即调用系统的0级别
[root@ddkk.com ~]# init 6
#重启，即调用系统的6级别
```
