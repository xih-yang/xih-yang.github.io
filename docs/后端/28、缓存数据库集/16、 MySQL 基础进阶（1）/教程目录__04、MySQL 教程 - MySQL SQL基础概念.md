**1、** 什么是SQL；

SQL是英文（Structured Query Language），结构化查询语言。SQL其实也是一种语言，就像Python是一门语言一样，SQL也有自己的规范和语法。

**2、** 什么是数据；

我们经常说数据库，数据库就是用来存储数据的。你的手机通讯录就是数据，你的身份信息是数据，数据在生活中到处都存在。
