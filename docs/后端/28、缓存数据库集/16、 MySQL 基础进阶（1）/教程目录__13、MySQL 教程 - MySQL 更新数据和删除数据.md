# 13、MySQL 教程 - MySQL 更新数据和删除数据
- 来源：https://ddkk.com/zhuanlan/db/mysql/5/13.html
- 分类：缓存数据库
- 分组：教程目录
前面讲了数据的新增和查看操作，增删改查就剩下更新和删除数据操作，所以本篇就介绍如何更新一个表内的数据和如何删除表内数据。

**更新数据**

语法格式：update 表名set 字段=值[where条件]；

建议都有where，要不然就是更新全部。

命令举例：把luly的年龄修改成18

这里要注意下，更新语句没有报错也不一定代表数据更新了，如果数据不存在，执行了更新语句，发现有0行受影响，那么其实是没有进行更新。

**删除数据**

删除是不可逆的，删除有风险，需要谨慎。

语法格式：delete from 表名[where 条件];

命令举例：删除学生表中性别是男的学生数据
