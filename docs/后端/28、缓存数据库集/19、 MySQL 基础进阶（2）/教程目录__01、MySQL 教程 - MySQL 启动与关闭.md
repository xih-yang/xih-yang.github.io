## 三、启动与关闭

mysql的命令在于多使用，一段时间不用就会记忆模糊，我就是因为经常忘老是需要查一下才觉得记下来很有必要，至少以后还可以看看自己的笔记印象深刻一点，这也是我开始写博客的初衷，很多东西就是需要看一眼才能想起来。

这里主要介绍的是windows下操作，因为自己的电脑装虚拟机太卡了。

### 启动：

mysql -h host -u uesr -p host表示连接的主机地址，如果是本记的话一般写127.0.0.1或localhost，或者直接省略

uesr是配置mysql时设置的用户名，一般是root；这条命令输入完成后会提示你输入密码

我这里直接在用户目录下输入命令使用为添加过环境变量，没有添加的需要到mysql的安装目录下使用命令；另外，由于自己练习一般都是自己的电脑当主机，因此-h host常常省略。

正确输入密码后有上面所示界面，mysql> 提示等待接受输入的命令。

这里可以看到一些小提示：

比如每一条语句的命令要以‘ ；’或‘ \g ’ 结束（也不完全是，比如退出mysql时的命令可以不带分号，后面会看到。）；

客户端的连接id，这个数字记录了MySQL服务到目前为止连接的次数，每连一次就加1，这里是8 ；

版本信息，这里是5.7.17，如果后面带beta表示测试版，带standard表示标准版；

输入‘help；’ 或 ‘\h’ 来获得一些提示信息；

在某一语句未输完的末尾加 ‘ \c ’ 来取消当前命令的输入重新输入新的命令。

### 退出：

退出MySQL可以用quit或exit，注意，退出命令不带分号也可正确执行。
