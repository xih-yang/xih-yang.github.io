SQL，又称结构化查询语言 (Structured Query Language)，是一种数据库查询和程序设计语言，用于存取数据以及查询、更新和管理关系数据库系统

在本课程中，我们将学习如何使用 SQL 访问和处理数据系统中的数据。

所用的数据库包括：MySQL、SQL Server、Access、Oracle、Sybase、DB2 等等
