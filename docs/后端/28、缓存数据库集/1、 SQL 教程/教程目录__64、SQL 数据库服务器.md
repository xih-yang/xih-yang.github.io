# 64、SQL 数据库服务器
- 来源：https://ddkk.com/zhuanlan/db/sql/64.html
- 分类：缓存数据库
- 分组：教程目录
如果我们开发的网站想要存储数据在数据库并从数据库显示数据，那么 Web 服务器必须能使用 SQL 语言访问数据库系统。

如果我们开发的 Web 服务器托管在互联网服务提供商（ISP，全称 Internet Service Provider），那么必须寻找 SQL 主机计划

最常见的 SQL 主机数据库是 MySQL、MS SQL Server 、Oracle 和 MS Access

可以在Windows 和 Linux/UNIX 操作系统上运行 SQL 主机数据库

下面是主流的数据库系统支持的操作系统平台

MSSQL Server

可以运行在 Windows 和 Linux 操作系统上

MySQL/MariaDB 推荐

可以跨平台的数据库系统，可以运行在 Windows, Mac OS X 和 Linux/UNIX 操作系统

Oracle Database

可以跨平台的数据库系统，可以运行在 Windows, Mac OS X 和 Linux/UNIX 操作系统

**MS Access** (只建议用于小型网站)

只能在运行在 Windows OS
