# 67、MySQL DATE() 函数
- 来源：https://ddkk.com/zhuanlan/db/sql/67.html
- 分类：缓存数据库
- 分组：教程目录
MySQL DATE() 函数提取日期或日期/时间表达式的日期部分

```sql
DATE(date)
```

参数
说明

date
一个合法的日期表达式

## 范例

我们可以使用下面的 SQL 语句返回当前日期时间和当前日期时间中的日期部分

```sql
SELECT NOW(), DATE(NOW);
```

运行结果显示如下

```sql
mysql> SELECT NOW(), DATE(NOW());
+---------------------+-------------+
| NOW()               | DATE(NOW()) |
+---------------------+-------------+
| 2018-05-18 10:20:56 | 2018-05-18  |
+---------------------+-------------+
```
