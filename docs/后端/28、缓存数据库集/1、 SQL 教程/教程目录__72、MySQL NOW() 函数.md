# 72、MySQL NOW() 函数
- 来源：https://ddkk.com/zhuanlan/db/sql/72.html
- 分类：缓存数据库
- 分组：教程目录
MySQL NOW() 函数返回当前的日期时间，精确到秒

```sql
NOW()
```

### 范例

我们可以用 NOW() 函数显示当前的时间

```sql
SELECT NOW();
```

运行结果如下

```sql
mysql> SELECT NOW();
+---------------------+
| NOW()               |
+---------------------+
| 2017-05-18 09:50:48 |
+---------------------+
```
