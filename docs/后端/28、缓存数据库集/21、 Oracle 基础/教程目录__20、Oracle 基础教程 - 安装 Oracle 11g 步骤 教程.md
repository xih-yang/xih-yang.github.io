# 20、Oracle 基础教程 - 安装 Oracle 11g 步骤 教程
- 来源：https://ddkk.com/zhuanlan/db/oracle/3/20.html
- 分类：缓存数据库
- 分组：教程目录
**操作系统：Window Server 2008 R2**

**数据库：Oracle 11.2.0.1**

**任务：安装Oracle ASM单实例数据库**

## 1. 安装grid

安装gird前需要首先要创建ASM磁盘，由于在Windows下使用ASM，不能对硬盘进行分区操作，须首先创建裸设备。

### 1.1 创建裸设备

（1）打开磁盘管理器

（2）磁盘2点击右键，选择**联机**

（3）其上点击右键，**初始化硬盘**

（4）选择磁盘分区形式，**2T以下的盘可以选者MBR**

（5）磁盘上点击右键，选择新建简单卷

点击下一步

点击下一步

选择**不分配驱动器号和驱动器路径**，点击下一步

选择**不要格式化这个卷**，点击下一步

点击完成，完成卷初始化的设置

目前磁盘的状态是**基本，联机，raw分区**

### 1.2 创建ASM磁盘组

在grid软件包里提供了一个asmtoolg图形界面操作和asmtool命令行界面，位于grid文件夹的asmtool文件夹里，双击asmtoolg。

点击下一步

选择映射格式raw的卷点击下一步

点击完成

### 1.3 执行grid安装

（1）打开grid文件夹，双击setup文件

（2）选择**安装和配置独立服务器的网格结构**

（3）选择默认的语言选项

（4）创建ASM磁盘组，填写磁盘组名，冗余选择“外部”，并选中选中新加入的磁盘路径。

（5）设置asm管理的密码

（6）使用默认设置点击下一步

（7）系统执行先决条件检查后，点击完成，系统开始安装grid组件

安装完成，点击关闭。

## 2. 安装database

（1）打开database文件夹，双击setup文件

（2）点击下一步

（3）选择**创建和配置数据库**

（4）选择服务器类，点击下一步

（5）选择单实例数据库安装，点击下一步（RAC数据库是多台机器运行同样一个实例，可以提高数据的服务能力和容错能力）

（6）选择高级安装，点击下一步

（7）默认语言安装

（8）选择企业版，点击下一步

（9）采用默认设置，点击下一步

（10）选择一般用途/事务处理，点击下一步

（11）设置实例名称

（12）调整内存大小；调整到74%，点击下一步

（13）选择数据库存储选项为**自动存储管理**，输入安装grid时为ASMSNMP输入的密码，点击下一步

（14）不启动备份

（15）选择asm中存在的data磁盘组，点击下一步

（16）为所有的用户采用同样一个口令

（17）点击完成，系统会自动安装oracle

安装完成，点击关闭

## 3. 安装client 端

（1）打开client文件夹，双击setup文件

（2）选择**管理员**安装类型，点击下一步

（3）选择默认的语言选项，点击下一步

（4）采用默认设置，点击下一步

（5）点击完成，系统会自动安装

安装完成，点击关闭

## 4. 配置Net Manager

（1）打开Net Manager

（2）添加服务名

点击绿色加号，填写网络服务名，点击下一步

选择TCP/IP，点击下一步

填写主机名，端口号，点击下一步

填写服务名，点击下一步

点击测试

点击关闭；点击完成

点击文件，保存网络配置
