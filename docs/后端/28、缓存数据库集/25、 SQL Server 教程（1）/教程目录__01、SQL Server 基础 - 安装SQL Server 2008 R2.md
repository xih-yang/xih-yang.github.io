DBMS即数据库管理系统，用来建立、使用和维护数据库；DBAS即数据库应用系统，它是在DBMS支持下建立的计算机应用系统。

SQL(结构化查询语言)用于存取数据以及查询、更新和管理关系数据库系统，不同的DBMS用的SQL通常都是在标准的SQL上进行了扩展，如SQL Server中将之扩展为T-SQL，Oracle中将之扩展为PL/SQL。

在数据库应用开发中，需求分析和设计是放在最前面的，通常还要掌握一些建模方法。但它们可以说是数据库应用开发的通用方法，所以不列在SQL Server学习笔记中。刚开始接触数据库，这些内容也是非常必要的，以后慢慢写在别的笔记里吧。
