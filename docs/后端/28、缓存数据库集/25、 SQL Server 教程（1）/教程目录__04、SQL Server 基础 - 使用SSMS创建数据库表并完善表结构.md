数据表的完整性问题大多是由于设计不当引起的，创建表的时候就应当保证以后的录入是正确的，也就是错误的、不符合要求的数据应当不允许录入。

```java
数据完整性=可靠性+精确性
```

要保证数据的完整性，就要实施完整性约束。

#### 四种完整性约束

①域完整性：列值的约束，如数据类型、位数、范围。

约束方法：检查约束、默认值约束、非空约束。

②实例完整性：行和行间不能重复。

约束方法：唯一约束、主键约束、标识列。

③引用完整性：某一列值需来源于另外一张表中。

约束方法：外键约束。

④自定义完整性：自己定义的一些约束。

约束方法：触发器。
