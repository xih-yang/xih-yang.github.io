## 什么是 XML ？

- XML 是可扩展标记语言 ( EXtensible Markup Language )
- XML 是一种很像 HTML 的标记语言
- XML 的设计的初衷是传输数据，而不是显示数据
- XML 标签没有被预定义。使用者需要自行定义标签
- XML 被设计为具有自我描述性
- XML 是 W3C 的推荐标准

## XML 和 HTML 之间的差异

**1、** XML设计的初衷是传输数据，它的着重点是数据的内容；

**2、** HTML设计的初衷是显示数据，它的着重点是数据的外观；

**3、** XML不是HTML的替代，也不是要代替HTML；

## XML 不会做任何事情

也许这有点难以立即，但 XML 确实是不会做任何事。

XML被设计用来结构化、存储以及传输信息

假如我们有一张小红写给小明的便签 如果用笔写在便签纸上，内容可能就是

```xml
小明:
    I miss you so much
                    小红
```

如果用XML 格式来表示，可能就是

#### xiaohong-love-note.xml

```xml
<note>
<to>小明</to>
<from>小明</from>
<heading>短信</heading>
<body>I miss you so much</body>
</note>
```

上面的这条 XML 便签具有自我描述性。它包含了发送者和接受者的信息，同时拥有标题以及消息主体。

但这个XML 文档仍然没有做任何事情。它仅仅是包装在 XML 标签中的纯粹的信息。

我们需要开发恰当的软件或者程序，才能传送、接收和显示出这个 XML 文档

## XML 可以让我们发明自己的标签

上面范例中小红的情书 **xiaohong-love-note.xml** 的标签没有在任何 XML 标准中定义过（比如 `` 和 ``），这些标签是由 XML 文档的创作者发明的

这是因为 XML 语言没有预定义的标签。

HTML 中使用的标签都是预定义的，HTML 文档只能使用在 HTML 标准中定义过的标签（如 `>`h1>` 等等

XML允许创作者定义自己的标签和自己的文档结构

## XML 不是 HTML 的替代，而是补充

**XML 是对 HTML 的补充**

XML不会替代 HTML 理解这一点很重要

在大多数 WEB 应用程序中，XML 用于传输数据，而 HTML 用于格式化并显示数据

对XML 最好的描述是：

**XML 是独立于软硬件的信息传输工具**

## XML 是 W3C 的推荐标准

XML在 1998 年 2 月 10 日正式成为 W3C 的推荐标准

## XML 无所不在

当前，XML 在信息传出中起到的作用非常巨大，唯一能与它匹肩的只有 JSON

## 总之

XML是各种应用程序之间进行数据传输的最常用的工具
