XMLHttpRequest 对象用于在后台与服务器交换数据

XMLHttpRequest 对象是 **开发者的梦想** ，因为我们能够：

- 在不重新加载页面的情况下更新网页
- 在页面已加载后从服务器请求数据
- 在页面已加载后从服务器接收数据
- 在后台向服务器发送数据

如果要深入学习 XMLHttpRequest 对象的知识，请移步我们的 XML DOM 教程

## 创建一个 XMLHttpRequest 对象

主流的浏览器（IE7+、Firefox、Chrome、Safari 和 Opera）都有内建的 XMLHttpRequest 对象

创建XMLHttpRequest 对象的语法：

```xml
xmlhttp=new XMLHttpRequest();
```
