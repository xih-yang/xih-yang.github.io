# 24、XML 相关技术
- 来源：https://ddkk.com/zhuanlan/xml/xml/24.html
- 分类：其他语言
- 分组：教程目录
下表是和 XML 相关的技术列表

名称
简介

XHTML (可扩展 HTML)
更严格更纯净的基于 XML 的 HTML 版本

XML DOM (XML 文档对象模型)
访问和操作 XML 的标准文档模型

XSL (可扩展样式表语言)
XSL 包含三个部分

|-- XSLT
(XSL 转换) 把 XML 转换为其他格式

|-- XSL-FO
(XSL 格式化对象)- 用于格式化 XML 文档的语言

|-- XPath
用于导航 XML 文档的语言

XQuery (XML 查询语言)
基于 XML 的用于查询 XML 数据的语言

DTD (文档类型定义)
用于定义 XML 文档中的合法元素的标准

XSD (XML 架构)
基于 XML 的 DTD 替代物

XLink(XML 链接语言)
在 XML 文档中创建超级链接的语言

XPointer (XML 指针语言)
允许 XLink链接指向 XML 文档中具体的部分

SOAP (简单对象访问协议)
用于在 HTTP 之上交换信息的基于 XML 的协议

WSDL (Web 服务描述语言)
用于描述网络服务的基于 XML 的语言

RDF (资源描述框架)
用于描述网络资源的基于 XML 的语言

RSS (真正简易聚合)
聚合新闻以及类新闻站点内容的格式

SVG (可伸缩矢量图形)
定义 XML 格式的图形
