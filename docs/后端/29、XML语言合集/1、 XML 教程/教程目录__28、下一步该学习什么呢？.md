XML可用于交换、共享和存储数据

XML文档形成 树状结构, 在 "根" 和 "叶子" 的分支开始的

XML有非常简单的 语法规则

带有正确语法的 XML 是 "形式良好" 的。有效的 XML 是针对 DTD 进行验证的

XSLT 用于把 XML 转换为其他格式，比如 HTML5

主流浏览器都有一个内建的 XML 解析器 ，可读取和操作 XML

DOM(Document Object Model) 定义了一个访问 XML 的标准方式

XMLHttpRequest 对象提供了一个网页加载后与服务器进行通信的方式

XML命名空间 提供了一种避免元素命名冲突的方法

CDATA 区域内的文本会被解析器忽略

我们的XML 范例 也代表了这个 XML 教程总结

## 下一步学习什么呢？

我们推荐学习 XML DOM 和 XSLT

如果你想要学习更多有关验证 XML 的知识，我们推荐学习 DTD 和 XML Schema

下面是为每个知识点做的简单介绍

## XML DOM（Document Object Model）

XMLDOM 定义了一种访问和处理 XML 文档的标准方式

XMLDOM 是平台和语言独立的，可用于任何编程语言，如 Java、JavaScript

如果想深入学习 DOM ，请移步我们的 XML DOM 基础教程

## XSLT（XML 样式表语言转换）

XSLT 是 XML 文件的样式表语言

使用XSLT，可以把 XML 文档转换为其他格式，比如 HTML5

如果想深入学习 XSLT ，请移步我们的 XSLT 基础教程

## XML DTD（文档类型定义）

DTD的目的是定义 XML 文档中合法的元素、属性和实体

使用DTD，每个 XML 文件可以随身携带它自己的格式的描述

DTD可以被用来确认程序收到的数据格式是否有效

如果想深入学习 DTD ，请移步我们的 DTD 教程

## XML Schema

XMLSchema 是一种基于 XML 的 DTD 替代

XMLSchema 支持数据类型，且使用 XML 语法

如果想深入学习 XML Schema，请移步我们的 XML Schema 基础教程
