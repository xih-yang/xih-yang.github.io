## 我们已经学习了 DTD，下一步学习什么？

> 下一步应当学习 XML Schema

XMLSchema 是用于定义 XML 文档的合法元素，类似 DTD。 很久以前大家认为 XML Schema 很快会将 DTD 取而代之，被用在大部分的网络应用程序中。

> 然后并没有，出了个 JSON 差点把 XML 给 代替了

XMLSchema 是基于 XML 的 DTD 替代物。

与DTD 不同，XML Schema 支持数据类型和命名空间

你可以学习我们的《XML Schema 教程》，来了解更多有关 XML Schema 的知识
