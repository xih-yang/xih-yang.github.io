# 01、XPath 基础教程
- 来源：https://ddkk.com/zhuanlan/xml/xpath/1.html
- 分类：XML语言教程
- 分组：教程目录
XPath 是一门在 XML 文档中查找信息的语言。XPath 可用来在 XML 文档中对元素和属性进行遍历

XPath 是 W3C XSLT 标准的重要组成部分，并且 XQuery 和 XPointer 都构建于 XPath 表达之上

因此，对 XPath 的理解是很多高级 XML 应用的基础
