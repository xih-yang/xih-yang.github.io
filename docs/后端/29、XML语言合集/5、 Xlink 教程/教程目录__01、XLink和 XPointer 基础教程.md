**XLink** 标准定义了如何在 XML 文档中创建**超级链接**

> 学会 XLink 和 XPointer 不能帮你找到工作，不过可以提高你的技术见解

**XPointer** 则允许这些超级链接指向 XML 文档中的更多具体部分
