## XLink基础教程总结

在本教程中，我们学习在 XML 文档中创建超级链接的一种标准方法。

相信你已经明白了 XML 中的链接被分为两个部分：XLink和 XPointer

- XLink定义了一套在 XML 文档中创建超级链接的标准方法。
- XPointer 使超级链接有能力指向 XML 文档中更多具体的部分

如果你需更多有关 XLink的知识，请浏览我们的《 XLink参考手册 》
