# 02、XQuery 简介
- 来源：https://ddkk.com/zhuanlan/xml/xquery/2.html
- 分类：XML语言教程
- 分组：教程目录
XQuery 的最简单的解释方式应该是

> XQuery 与 XML 的关系，等同于 SQL 与 数据库表的关系

所以，XQuery 被设计用来查询 XML 数据 - 不仅仅限于 XML 文件，还包括任何可以 XML 形态呈现的数据，包括数据库

## 您应该具备的基础知识

在我们继续学习之前，我们希望你对下面的知识有基本的了解：

- HTML / XHTML
- XML / XML 命名空间
- XPath

## XQuery 是什么?

- XQuery 是用于 XML 数据查询的语言
- XQuery 对 XML 的作用类似 SQL 对数据库的作用
- XQuery 建立在 XPath 表达式之上
- XQuery 被所有主要的数据库引擎支持（IBM、Oracle、Microsoft等等）
- XQuery 是 W3C 标准

## XQuery 与 XML 的关系

XQuery 是用来从 XML 文档查找和提取元素及属性的语言

这是一个 XQuery 解决实际问题的例子：

> 从存储在名为 cd_catalog.xml 的 XML 文档中的 CD 集那里选取所有价格低于 10 美元的 CD 记录

## XQuery 与 XPath 的关系

XQuery 1.0 和 XPath 2.0 具有相同的数据模型，并支持相同的函数和运算符

假如您已经学习了 XPath，那么学习 XQuery 也是很轻松的

你可以在我们的《XPath 教程》 中阅读更多有关 XPath 的知识

## XQuery - 使用场景

XQuery 可用于：

- 提取信息以便在网络服务中使用
- 生成摘要报告
- 把 XML 数据转换为 XHTML
- 为获得相关信息而搜索网络文档

## XQuery 是 W3C 推荐标准

XQuery 与多种 W3C 标准相兼容，比如 XML、Namespaces、XSLT、XPath 以及 XML Schema

XQuery 1.0 在 2007年1月23日 被确立为 W3C 推荐标准

你可以阅读我们的《W3C 教程》获得更多有关 W3C 的 XQuery 活动的信息
