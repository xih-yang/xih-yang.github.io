## JEP 316 ： 替代内存设备上的堆分配

通过Java 10 中的这一增强，现在用户可以指定替代内存设备，例如 NV-DIMM 到 HotSpot VM 来分配 Java 堆空间。用户需要使用新选项 -XX:AllocateHeapAt 将路径传递到文件系统。

```java
-XX:AllocateHeapAt=~/etc/heap
```

此选项采用文件路径并进行内存映射以达到所需的结果。其他堆标志如 -Xmx、-Xms 继续工作。
