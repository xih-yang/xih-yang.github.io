## JEP 312 ： 线程本地握手

在JDK 10 中，为 JVM 引入了一个新选项-XX:ThreadLocalHandshakes。此选项仅适用于基于 x64 和 SPARC 的机器。

此选项可用于提高 VM 性能。它允许在不创建全局 VM 安全点的情况下对应用程序线程进行回调。因此允许 JVM 停止单个线程而不停止所有线程。

由于此选项并非适用于所有平台，因此其他平台将回退到正常的安全点。
