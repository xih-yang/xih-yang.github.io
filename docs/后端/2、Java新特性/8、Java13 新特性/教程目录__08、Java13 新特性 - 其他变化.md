# 08、Java13 新特性 - 其他变化
- 来源：https://ddkk.com/zhuanlan/java/java13/8.html
- 分类：Java 13 新特性
- 分组：教程目录
Java 13 向 java.nio.file.FileSystems 引入了三种新方法，可以轻松地将文件内容视为文件系统。

- newFileSystem(Path)
- newFileSystem(Path, Map``)
- newFileSystem(Path, Map``, ClassLoader)

以下是添加到语言的其他主要更改。

- java.time ： 添加了日本时代名称
- javax.crypto ： MS Cryptography Next Generation (CNG) 支持
- javax.security ： jdk.sasl.disabledMechanisms 属性添加禁用 SASL 机制
- javax.xml.crypto ： 引入字符串常量来表示规范的 XML 1.1 URI
- javax.xml.parsers ： 添加了用于实例化 DOM 和 SAX 工厂以支持命名空间的方法
- Unicode 支持升级到 12.1 版
- 添加了 Kerberos 主体名称规范化支持，支持跨领域引用。

## API 标记为删除

- JDK 1.4 之前的 SocketImpl 实现
- javax.security.cert API
- rmic
- javadoc 工具旧功能
