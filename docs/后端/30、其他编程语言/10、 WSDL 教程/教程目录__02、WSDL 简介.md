## WSDL 是什么?

- WSDL 指网络服务描述语言
- WSDL 使用 XML 编写
- WSDL 是一种 XML 文档
- WSDL 用于描述网络服务
- WSDL 也可用于定位网络服务
- WSDL 还不是 W3C 标准

## WSDL 可描述网络服务（Web Services）

WSDL 是网络服务描述语言 (Web Services Description Language)。

WSDL 是一种使用 XML 编写的，可描述某个 Web service 的文档。

WSDL 可以规定服务的位置，以及此服务提供的操作或方法

## WSDL 推荐标准的发展史

在2001 年 3 月，WSDL 1.1 由 IBM、微软作为一个 W3C 记录（W3C note）提交到有关 XML 协议的 W3C XML 活动小组，目的是用于描述网络服务

> W3C 记录仅供讨论是一项 W3C 记录的发布并不代表它已被 W3C 或 W3C 团队亦或任何 W3C 成员认可

在2002 年 7 月，W3C 发布了第一个 WSDL 1.2 工作草案
