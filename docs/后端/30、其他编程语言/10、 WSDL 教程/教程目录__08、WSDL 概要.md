## 我们已经学习了 WSDL，下一步学习什么呢？

我们建议下一步应该学习 SOAP 和 Web Services

## SOAP

SOAP 是简单对象访问模型，是一种基于 XML 的简易协议，允许应用程序通过 HTTP 来交换信息。

简单的说：SOAP 是用于访问 web 服务的协议。

你可以访问我们的 SOAP 教程 来学习更多有关 SOAP 的知识

## Web Services

Webservices 可把应用程序转换为 web 应用程序

Webservices 让我们可以通过使用 XML，在应用程序间传送消息

你可以访问我们的 Web services 教程 来学习更多有关 Web services 的知识
