Swift 是开发 Mac APP 和 iOS APP 的语言

Swift 是一种支持多编程范式和编译式的开源编程语言，用于开发 iOS，OS X 和 watchOS 应用程序

Swift 结合了 C 和 Objective-C 的优点并且不受 C 兼容性的限制

Swift 在 Mac OS 和 iOS 平台可以和 Object-C 使用相同的运行环境

## 谁适合阅读本教程 ？

本教程适合想从事移动端(iPhone )开发或 OS X 应用的编程人员

本教程所有范例基于 Xcode 8.2.1 和 Swift 3.0.2 的语法格式开发测试

## 第一个 Swift 程序

第一个Swift 程序当然从输出 "Hello, World!" 开始

```swift
/* 我的第一个 Swift 程序 */
print("Hello, World!")
```
