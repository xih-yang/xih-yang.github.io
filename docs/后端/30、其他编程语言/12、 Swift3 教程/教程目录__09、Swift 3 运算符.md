运算符用于执行程序代码运算，会针对一个以上操作数项目来进行运算

Swift 提供了以下几种运算符

- 算术运算符
- 比较运算符

- 位运算符
- 赋值运算符
- 区间运算符
- 其他运算符

## 算术运算符

下表列出了 Swift 语言支持的算术运算符

假设变量 A 为 17，变量 B 为 7

运算符
描述
范例

+
加号
A + B 结果为 24

−
减号
A − B 结果为 10

*
乘号
A * B 结果为 119

/
除号
A / B 结果为 2

%
求余
A % B 结果为 3

**注意：** Swift 3 中已经取消了 ++ 、--

### 范例

下面代码是演示了算术运算的使用

```swift
import Cocoa
var A = 17
var B = 7
print("A + B 结果为：\(A + B)")
print("A - B 结果为：\(A - B)")
print("A * B 结果为：\(A * B)")
print("A / B 结果为：\(A / B)")
print("A % B 结果为：\(A % B)")
A += 1 
print("A += 1 后 A 的值为 \(A)")
B -= 1
print("B -= 1 后 B 的值为 \(B)")
```

运行以上 Swift 范例，输出结果如下

```swift
$ swift main.swift
A + B 结果为：24
A - B 结果为：10
A * B 结果为：119
A / B 结果为：2
A % B 结果为：3
A += 1 后 A 的值为 18
B -= 1 后 B 的值为 6
```

## 比较运算符

下表列出了 Swift 语言支持的比较运算符

假设变量 A 为 17，变量 B 为 17

运算符
描述
范例

==
等于
(A == B) 为 false

!=
不等于
(A != B) 为 true

>
大于
(A > B) 为 true

大于等于
(A >= B) 为 true

>
按位右移。右移操作符（> 1（11111111 右移一位）的结果。蓝色数字表示被移动位，灰色表示被丢弃位，空位用橙色的0填充。

### 范例

下面代码是演示了位运算的使用

```swift
import Cocoa
var A = 60  // 二进制为 0011 1100

print("A|B 结果为：\(A|B)")

print("~A 结果为：\(~A)")
```

运行以上 Swift 范例，输出结果如下

```swift
$ swift main.swift
A&B 结果为：12
A|B 结果为：61
A^B 结果为：49
~A 结果为：-61
```

## 赋值运算

下表列出了 Swift 语言的基本赋值运算

运算符
描述
范例

=
简单的赋值运算，指定右边操作数赋值给左边的操作数
C = A + B 将 A + B 的运算结果赋值给 C

+=
相加后再赋值，将左右两边的操作数相加后再赋值给左边的操作数
C += A 相当于 C = C + A

-=
相减后再赋值，将左右两边的操作数相减后再赋值给左边的操作数
C -= A 相当于 C = C - A

*=
相乘后再赋值，将左右两边的操作数相乘后再赋值给左边的操作数
C *= A 相当于 C = C * A

/=
相除后再赋值，将左右两边的操作数相除后再赋值给左边的操作数
C /= A 相当于 C = C / A

%=
求余后再赋值，将左右两边的操作数求余后再赋值给左边的操作数
C %= A is equivalent to C = C % A

>=
按位右移后再赋值
C >>= 2 相当于 C = C >> 2

&=
按位与运算后赋值
C &= 2 相当于 C = C & 2

^=
按位异或运算符后再赋值
C ^= 2 相当于 C = C ^ 2

|=
按位或运算后再赋值
C |= 2 相当于 C = C | 2

### 范例

下面代码是演示了赋值运算的使用

```swift
import Cocoa
var A = 10
var B = 20
var C = 100
C = A + B
print("C 结果为：\(C)")
C += A
print("C 结果为：\(C)")
C -= A
print("C 结果为：\(C)")
C *= A
print("C 结果为：\(C)")
C /= A
print("C 结果为：\(C)")
 C %= A
 print("C 结果为：\(C)")
 C <<= A
 print("C 结果为：\(C)")
 C >>= A
 print("C 结果为：\(C)")
 C &= A
 print("C 结果为：\(C)")
 C ^= A
 print("C 结果为：\(C)")
 C |= A
 print("C 结果为：\(C)")
```

运行以上 Swift 范例，输出结果如下

```swift
C 结果为：30

C 结果为：0

C 结果为：10
```

### 范例

下面为运算符优先级的使用

```swift
import Cocoa
var A = 0
A = 2 + 3 * 4 % 5
print("A 的值为：\(A)")
```

运行以上 Swift 范例，输出结果如下

```swift
$ swift main.swift
A 的值为：4
```

根据运算符优先级，可以将以上程序的运算解析为以下步骤，表达式相当于

```swift
2 + ((3 * 4) % 5)
```

**1、** 计算(3*4)=12，所以表达式相当于；

```swift
2 + (12 % 5)
```

**2、** 计算12%5=2，所以表达式相当于；

```swift
2 + 2
```

此时可以容易地看出计算的结果为 4
