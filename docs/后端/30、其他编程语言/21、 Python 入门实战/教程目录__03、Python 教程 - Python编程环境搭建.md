## 1 前言

对于较大型的项目，显然用简单的文本工具编写代码交由命令行执行的方式已不可取，此时应使用集成开发环境，这里介绍最为流行的PyCharm（Eclipse这里不做介绍）。

PyCharm 是 JetBrains 公司（www.jetbrains.com）研发，用于开发 Python 的 IDE 开发工具。

## 2 PyCharm配置

### 2.1 下载

下载地址：[下载地址](https://www.jetbrains.com/pycharm/download/#section=windows)

PyCharm有2个版本，分别是 Professional（专业版）和 Community（社区版）。其中，专业版是收费的，可以免费试用30天；而社区版是完全免费的，作为开发者，当然选择专业版，甚至将Anaconda一起下载，至于PyCharm的破解则较为简单，可自行百度。

### 2.2 安装

点击exe运行，选择安装位置，建议将安装位置上PyCharm带有空格的路径信息去除。

接下来，安装功能选择建议全选，即将“64-bit launcher”、“Add ‘Open Folder as Project’”、“.py”、“Add launcher dir to the PATH”，选择“Next”，点击“Install”安装即可。接下来就是激活
