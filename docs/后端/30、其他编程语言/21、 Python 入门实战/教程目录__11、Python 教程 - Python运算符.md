## 1 Python 运算符

运算符用于对变量和值执行操作。

Python 在以下组中划分运算符：

- 算术运算符
- 赋值运算符
- 比较运算符
- 逻辑运算符
- 身份运算符
- 成员运算符
- 位运算符
