Perl 又名**实用报表提取语言**， 是 Practical Extraction and Report Language 的缩写

Perl 是由 拉里·沃尔（Larry Wall）于1987年12月18日发表的，高级、通用、直译式、动态的程序语言

Perl 设计之初就借鉴了C、sed、awk、shell脚本以及很多其他编程语言的特性

当然了，Perl 最重要的特性是内部集成了正则表达式的功能，以及巨大的第三方代码库 CPAN

## 谁适合阅读本教程？

如果你之前从未接触过 Perl,或者你已经有了 Perl基础知识，想要了解更多模块的应用，那么，本教程非常适合你

## 学习本教程前需要了解的知识

在我们继续这份 Perl 基础教程之前，我们希望你了解一些基本的计算机编程术语

如果你学习过 PHP 等其他编程语言，那会让你更快的了解 Perl 编程
