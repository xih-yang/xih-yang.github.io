## 1、快速排序介绍

快速排序（QuickSort）是对冒泡排序算法的一种改进，快速排序算法通过多次比较和交换来实现排序。

## 2、快速排序基本思想

> 选一个 pivot 中心轴，将大于 pivot 的值放到 pivot 右边，小于 pivot 的值放到 pivot 左边，分别对左右两边的子序列重复前面的操作

## 3、快速排序流程：

- 设定一个分界值，通过分界值将数组分为左右两部分
- 大于或者等于分界值得数据集中到数组右边，小于分界值得数据集中到数组左边
- 左边和右边的数据可以独立排序，左侧和右侧数据可以继续取分界值进行排序，重复上述过程直到排序完成

## 4、代码实现

```java
public class QuickSort {
    public static void main(String[] args) {
        int[] arr = {
     23, 1, 34, -12, 23, 1, 3, 8, 65, 0, 5, 0, 24, 32, 9, 2};
        quickSort(arr, 0, arr.length - 1);
        System.out.println(Arrays.toString(arr));
    }
    public static void quickSort(int[] arr, int left, int right) {
        // 两个指针，分别指向最小索引和最大索引位置
        int l = left;
        int r = right;
        // 使用最左边的元素作为分界值
        int pivot = arr[l];
        // 将比 pivot 值小的放到左边，大的放到右边
        while (l < r) {
            // 在右边向左找，找到小于基准值 pivot 的值停止
            while (l < r && arr[r] >= pivot) {
                r--;
            }
            // 从左向右开始找，直到找到比基准值 pivot 大的元素就停止
            while (l < r && arr[l] <= pivot) {
                l++;
            }
            // 如果左边下标跟右边下标重叠，或者左边大于右边下标，元素扫描完毕
            if (l >= r) {
                break;
            }
            // 通过临时变量将左右两边指针位置元素交换
            int temp = arr[l];
            arr[l] = arr[r];
            arr[r] = temp;
        }
        // 将基准值与 l 或者 r 位置元素进行交换
        arr[left] = arr[l];
        arr[l] = pivot;
        // 将 l 和 r 错开，分组不包含分界值
        if (l == r) {
            l ++;
            r --;
        }
        // 现有 pivot 左侧分组数据递归进行排序
        if (left < r) {
            quickSort(arr, left, r);
        }
        // 现有 pivot 右侧分组数据递归进行排序
        if (right > l) {
            quickSort(arr, l, right);
        }
    }
}
```
