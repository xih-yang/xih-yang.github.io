# 3.1 概述
- 来源：https://ddkk.com/zhuanlan/orm/jfinal/21.html
- 分类：ORM框架
- 分组：3 Controller
Controller是JFinal核心类之一，该类作为MVC模式中的控制器。基于JFinal的Web应用的控制器需要继承该类。Controller是定义Action方法的地点，是组织Action的一种方式，一个Controller可以包含多个Action。Controller是线程安全的。
