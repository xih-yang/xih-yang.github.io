# 21、JavaScript Math对象的常用方法
- 来源：https://ddkk.com/zhuanlan/qianduan/javascript/1/21.html
- 分类：前端框架
- 分组：教程目录
Math.random() :返回0-1之间的随机数

math.max(num,num2,num3,…) 返回较大数

Math.min（num，num2,…） 返回较小

Math.abs(num) 绝对值

Math.ceil（num） 向上取整

```java
4.4=>5
```

Math.floor （num） 向下取整

```java
4.5=>4
```

Math.round() 四舍五入（整数，只看小数点后一位）

```java
4.59 => 5
```

Math.pow （x,y） x的y次方

Math.sqrt(x) 开平发

Math.sin( ) 正弦定理

Math.cos（） 余弦定理

Math.PI=3.141592653589793 或者引用到角度 Π

因为浮点数是有误差的，所有无法达到0.5

官网：[https://www.w3school.com.cn/js/js_math.asp](https://www.w3school.com.cn/js/js_math.asp)

补充：Math.PI 表示180度 一弧度=Math.PI/180
