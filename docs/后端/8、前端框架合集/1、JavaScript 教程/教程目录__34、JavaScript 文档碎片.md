如果需要一次性添加一万个节点：如下图

console.time（‘测试名’）：测试时间开始

console.timeEnd（‘测试名’）：测试时间结束

上面两种方法配合，功能是测试某段代码运行所开始到结束所耗费的时间。可以看出图中创建10000个节点并将其插入到body内需要大概35ms。

**文档碎片：**

如果我们需要添加十万个节点的话，耗费时间会更多，这样会很耗费计算机性能。因此我们需要提升计算机的性能，方法就是，我们先将一万个节点创建好，然后再去将创建的的一万节点一次性放入插入的标签内。如下图

相比较第一种节点插入的方法耗费的时间，第二种耗费的时间更短
