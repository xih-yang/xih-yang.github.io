十进制转二进制，再将二进制转八进制和十六进制

二进制转八进制：

规则：从右往左数，每三位一组，不足三位用0补齐，最后将每一组数转成八进制进制

```java
二进制转八进制   110  100  转八进制：6 4  
八进制转十进制    64=>6*8^1+4*8^0  = 52
```

二进制转十六进制：

规则：从右往左数，每四位一组，不足三位用0补齐，最后将每一组数转成十六进制

```java
二进制转十六    11  0100  转十六进制：3 4 
十六进制转十进制=> 3*16^1  + 4*16^0  = 5 2
```
