## 3. 相关知识点

### 3.1 初见编程语言

第一次听说编程语言，我想很多朋友都会跟我一样，感觉它有些神秘、有些高端、与我们有些距离感。

大家眼中的程序员，大多是出入高楼大厦的白领。整天坐在电脑屏幕前，编写着可能改变世界的代码。

程序员使用编程语言来编写程序，那么编程语言到底是啥东东呢。它有那么神奇吗，竟然能让计算机老老实实的干活。

其实就是程序员与计算机沟通的工具而已。

### 3.2 先来聊聊自然语言

有人笑谈说，人类是大型群居类哺乳动物。没错，人类的一大特点就是群居。既然是群居，那总是要沟通的，而语言就是用来，在不同个体之间沟通的交流工具。

人与人之间沟通使用的语言，是在人类社会发展过程中自然产生的语言，可以称之为自然语言。

自然语言是人类自然社会发展过程中逐渐形成的，所以它受历史影响、受地域影响，它是非常复杂的。例如咱们博大精深的汉语、再例如大家都学了好久却还说不出口的英语，都很复杂。一般情况下，学习一门自然语言，需要一个很长的过程，这个过程往往以年为单位计量。

既然语言是用来在不同个体之间沟通的，那么大家都得遵从语言的规则，才能互相理解。不然你说你的，我说我的，不按规矩来，就没法互相沟通了。

咱们学习英语的时候学习那些语法，就是自然语言的规则。

### 3.3 再来认识下编程语言

程序员要想与计算机进行沟通，对着计算机讲汉语、英语等自然语言，是行不通的。自然语言太复杂，计算机难以理解。此时就需要一种专门的语言，用来跟计算机进行沟通，这就是编程语言了。

编程语言是程序员和计算机之间沟通的语言，程序员得通过编程语言，来给计算机下命令，让计算机完成任务。

但是，计算机可不像人类那么聪明，计算机本质上是一个不知疲倦的机器，它只能按照程序员的指令完成既定任务。

所以编程语言不能太复杂了，毕竟计算机无法理解人类语言中的语气、腔调。编程语言是规则更加明确的语言，它有着非常固化的模式。

一般而言学习一门编程语言，只需要几个月的时间，就能初步达成与计算机沟通的目的。而且不同的编程语言，具备高度的相似性，掌握一门编程语言后，再学习其他编程语言是一件挺容易的事情。

所以明白了吧，学编程比学一门外语，那是简单很多滴。

## 5. 任务总结

说到底，编程语言，就是程序员与计算机沟通的工具语言，就是一些具备规则的文字、字符而已。按照规则编写的语言，就能让计算机听话、干活。

关键是这些规则它并不算难，只要多学多练，就能掌握它。
