## 1. 任务背景

对00后的朋友们来说，网站的确说不上神奇。他们小时候，可能就用过电脑或手机，访问过很多网站了。

但是对于我这样，一个农村出生的90后来说，网站一直是书本里才有的东西，我从没有真正访问过网站。

虽然我去过网吧玩过一些游戏，但那时候的网吧竟然大多数都是不联网的，大人小孩都在那里面玩着古老却有趣的单机游戏（印象最深刻的是当时异常火爆的CS和红警）。

直到小学五年级的那一年，我印象很深刻，一个很偶尔的机会我要去镇上。镇上这个词，其实指的是一个乡镇的中心地带，它往往是农村里面经济最发达的地方。

镇上的网吧是能联网的，所以我特意去了一趟网吧。当我哆哆嗦嗦的，按照记忆中书本讲述的方法，打开浏览器访问到人生中第一个网站。五颜六色的网页瞬间展示到我面前，我感觉我的手指好像穿透了时空，触摸到了全世界的风。

网站给我的第一印象，就是那么神奇，也在我内心埋下一颗种子。

后来我升入高中，对电脑有了更多了解。再后来，我考入大学，就读计算机相关专业，对网站有了更深刻的认识。

就如汽车站，聚集了很多汽车，等待人们的乘坐一般。

网站，聚集了很多网页，等待人们的访问。

**网站就是网页的集合**，这些网页共同为人们提供信息服务。例如百度网提供搜索服务，爱奇艺提供视频服务，淘宝网提供网上购物服务。

## 2. 任务目标

通过学习本文，各位看官，了解什么是网站、什么是网页即可。

## 3. 相关知识点

一个网站，往往是由很多网页组成的。例如百度，有首页，新闻页面、有地图页面。

网页是网站的组成部分，只有一个网页的网站未免也太单调了一点。我们日常访问的网站，大多数都是有用很多网页的。

## 4. 任务实操

随便打开一个网站验证下吧，是不是拥有很多网页？

## 5. 任务总结

可能没接触之前，觉得网站、网页挺神奇的。甚至我们已经见识过很多很多网站，还是觉得这东西，是技术含量挺高的。

其实网页本质上，就是一个文档，跟大家比较熟悉的记事本文件相似。在后续的学习中，我们将亲手去制作网页，让网页在我们的面前，不再神奇。
