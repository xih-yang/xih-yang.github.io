## 3. 相关知识点

### 3.1 文件类型

在学习编写网页之前，大家一定要掌握一个非常基础且不可或缺的概念，就是文件类型。

我们知道文件分为txt文本文件、word文件、excel表格文件、ppt演示文档、mp3音乐文件等等不同的类型。

那么电脑是怎么区分这些类型的呢，我们双击文件时，为什么电脑能使用对应的软件打开这个文件？

实际上，我们的电脑是通过文件的拓展名，来区分文件的，也是通过文件的拓展名，来决定打开文件时使用什么程序的。

例如：记事本编写的文件，拓展名是`.txt`；word编写的文档，拓展名是`.doc`或者`.docx` ，doc是早期使用的拓展名，后来又推出了docx；excel编写的表格闻到那个，拓展名是`.xls`或`.xlsx`；mp3音乐文件的拓展名，那就是`.mp3`了。

当我们双击某个文件时，电脑通过拓展名知道了该文件的类型，然后调用对应的程序打开该文件。

作为一名程序员来说，我们应该始终展示文件的拓展名，便于我们随时分析文件类型。
