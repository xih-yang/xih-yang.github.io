## 3. 相关知识点

### 3.1 元素、标签

在HTML中，元素是指的标签及标签的内容部分，而标签指的是尖括号括起来的部分。例如：

```java
<p>春眠不觉晓</p>
```

上面的整行代码，是html的段落元素。而中间的`春眠不觉晓`是该元素的内容，标签指的是``和`
`部分。

HTML中的标签，大多数都是成对使用的，有开始标签和结束标签，例如：``、``、``等等。

对于双标签来说，元素=开始标签+内容+结束标签。

HTML中还有一部分标签，无需成对，可以单独使用，例如换行标签`
