# 03、HTML5 新元素
- 来源：https://ddkk.com/zhuanlan/qianduan/html5/3.html
- 分类：前端框架
- 分组：教程目录
HTML5 添加了很多新元素及功能，比如 图形的绘制，多媒体内容，更好的页面结构，更好的形式 处理，和拖放元素操作，定位，包括网页 应用程序缓存，存储，网络工作者，等

同时也废除了 HTML 4.01 中的几个元素，这些元素在 HTML 5 中已经被删除或重新定义
