## 1. Bootstrap是什么

Bootstrap是Twitter开发的一种Web框架，所谓Web框架，可以简单的理解为别人写好的CSS样式库和JavaScript脚本库。我们可以拿来即用。

## 2. 为何要学习Bootstrap

Bootstrap实在是太经典了，提供了一系列统一的样式，非常规范标准，符合绝大多数人的审美。

最重要的，Bootstrap通过栅栏系统，提供了响应式的网站实现方案，即同一套代码，可以在不同尺寸的屏幕上正常运行。

Bootstrap之后的Web框架，基本都提供了响应式的支持，但是理念几乎都来源于栅栏系统。可见Bootstrap之经典、影响之深远。

所以不论是出于学习目的，还是出于使用目的，学习Bootstrap都是非常nice的。

## 3. Bootstrap历史地位

首先HTML、CSS、JS是整个Web前端开发领域的基石，是浏览器原生支持的基础语言/技术。

在此之上，就得提起jQuery，jQuery封装了JS里面的方法，提供了兼容大多数浏览器的且更加简洁易用的JS脚本库，在Web前端开发历史上占据了重要地位。

在这之后，就得提起Bootstrap了，Bootstrap提供了响应式开发的实现基础理念，在移动手机端网页开发越来越重要的时代，其作用不言而喻。

当然发展到今天，我们更多的使用现代的Web框架Vue/React/Angular，这几个框架更多的改变了页面元素和JS语言的交互方式。在页面样式显示层面也可以继续使用Bootstrap，并不冲突。

## 4. 小结

Bootstrap本质是CSS样式库加JS脚本库，拿来即用，非常方便。
