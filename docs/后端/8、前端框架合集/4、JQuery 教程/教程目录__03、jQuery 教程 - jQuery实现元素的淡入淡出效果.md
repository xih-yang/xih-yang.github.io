# 03、jQuery 教程 - jQuery实现元素的淡入淡出效果
- 来源：https://ddkk.com/zhuanlan/qianduan/jquery/1/3.html
- 分类：前端框架
- 分组：教程目录
### 1、fadeIn（）方法

> fadeIn() 用于淡入已隐藏的元素。

```java
$("#div").fadeIn();
```

### 2、fadeOut（）方法

> fadeOut() 方法用于淡出可见元素。

```java
$("#div").fadeOut();
```

### 3、fadeToggle（）方法

> fadeToggle() 方法可以在 fadeIn() 与 fadeOut() 方法之间进行切换。

```java
$("#div").fadeToggle();
```

### 4、fadeTo（）方法

> fadeTo() 方法允许渐变为给定的不透明度（值介于 0 与 1 之间）。

```java
$("#div").fadeTo("slow",0.6);
```
