# 08、jQuery 教程 - jQuery设置获取内容html()和text()
- 来源：https://ddkk.com/zhuanlan/qianduan/jquery/1/8.html
- 分类：前端框架
- 分组：教程目录
### html()方法

> 设置或者获取元素的内容(包括html标记)

```java
//设置元素内容
$('.div').html('<span>设置元素内容</span>');
//获取元素内容
$('.div').html();//html结构
```

### text()方法

> 设置或者获取元素的文本内容

```java
//设置元素文本内容
$('.div').text('修改了内容');
//获取元素文本内容
$('.div').text();//字符串
```
