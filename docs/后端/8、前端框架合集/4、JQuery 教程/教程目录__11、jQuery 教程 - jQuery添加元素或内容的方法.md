# 11、jQuery 教程 - jQuery添加元素或内容的方法
- 来源：https://ddkk.com/zhuanlan/qianduan/jquery/1/11.html
- 分类：前端框架
- 分组：教程目录
### 1、append()方法

> 在被选元素结尾添加新元素。

```java
<div class="add">好好学习，天天向上。</div>
<br>
<button>添加元素</button>
```

**效果：**

> 在被选元素内部结尾添加新元素。

### 2、prepend()方法

> 在被选元素的开头添加新元素。

```java
<div class="add">好好学习，天天向上。</div>
<br>
<button>添加元素</button>
```

**效果：**

> 在被选元素内部开头添加新元素。

### 3、after()方法

> 在被选元素之后添加新元素。

**效果：**

> 在被选元素外部之后添加新元素。

### 4、before()方法

> 在被选元素之前添加新元素。

**效果：**

> 在被选元素外部之前添加新元素。
