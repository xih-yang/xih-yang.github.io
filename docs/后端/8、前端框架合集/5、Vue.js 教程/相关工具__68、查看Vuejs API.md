# 68、查看Vuejs API
- 来源：https://ddkk.com/zhuanlan/qianduan/vuejs/68.html
- 分类：前端框架
- 分组：相关工具
Vuejs的API的查看方式，对于初学者需要适应。

想要读懂API的话，首先需要对Vuejs的各个部分有个明确的认识。

英文版： [https://vuejs.org/v2/api/](https://vuejs.org/v2/api/)

中文版： [https://cn.vuejs.org/v2/api/](https://cn.vuejs.org/v2/api/)

推荐大家在查看文档的时候，查看英文版。 很多专业的名词，例如： ‘minxin’, ‘component’ 都是原汁原味的。读起来更加明白一些。

建议每一位同学都要从头到尾看一下这里。 大约1个小时就可以全部看完，之后就会对Vuejs有个非常全面的了解~
