# 1、Groovy 概述
- 来源：https://ddkk.com/zhuanlan/java/groovy/1.html
- 分类：Groovy 教程
- 分组：教程目录
Groovy是一种基于Java平台的面向对象语言。 Groovy 1.0于2007年1月2日，其中Groovy 2.4是当前的主要版本。 Groovy通过Apache License v 2.0。

## Groovy的特点

Groovy中有以下特点:

- 同时支持静态和动态类型。
- 支持运算符重载。
- 本地语法列表和关联数组。
- 对正则表达式的本地支持。
- 各种标记语言，如XML和HTML原生支持。
- Groovy对于Java开发人员来说很简单，因为Java和Groovy的语法非常相似。
- 您可以使用现有的Java库。
- Groovy扩展了java.lang.Object。

Groovy的官方网站是[http://www.groovy-lang.org/](http://www.groovy-lang.org/)
