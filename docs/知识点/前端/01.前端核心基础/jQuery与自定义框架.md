# jQuery 与自定义框架

jQuery 是理解"早期前端如何提升开发效率"的重要切口，自定义框架封装则能帮助理解现代框架到底抽象了什么。

## 核心范围

- jQuery 选择器、事件、动画、AJAX、插件机制
- 常见后台管理系统的 jQuery 实战模式
- 原生框架封装：事件总线、模板拼接、组件雏形、工具函数库
- 封装分层：基础工具层、中级组件层、高级业务框架层

## 一、jQuery 核心知识点（必背）

### 1. 选择器（核心）
- **ID**：`$('#id')`
- **类**：`$('.class')`
- **标签**：`$('div')`
- **层级**：`$('ul li')`、`$('.box > p')`
- **筛选**：`:first`、`:last`、`:eq(index)`、`:has()`、`:visible`
- **查找**：`find()`、`parent()`、`children()`、`siblings()`
- **重点**：支持 CSS 选择器，简洁强大，查 DOM 效率高

### 2. 事件机制（必背）
- **绑定**：`on('click', function(){})`
- **解绑**：`off()`
- **一次性**：`one()`
- **简写**：`click()` / `hover()` / `submit()` / `change()`
- **重点**：事件委托
  ```js
  $(父元素).on('click', '子元素', fn)
  ```
  **优点**：动态生成元素也能绑定、减少绑定次数、性能高

### 3. DOM 操作（重点）
- **内容**：`html()`、`text()`、`val()`
- **类名**：`addClass()`、`removeClass()`、`toggleClass()`、`hasClass()`
- **属性**：`attr()`、`prop()`
- **样式**：`css()`
- **增删改**：`append()`、`prepend()`、`after()`、`before()`、`remove()`、`empty()`

### 4. 动画效果（常用）
- **显示隐藏**：`show()`、`hide()`、`toggle()`
- **淡入淡出**：`fadeIn()`、`fadeOut()`、`fadeToggle()`
- **滑动**：`slideDown()`、`slideUp()`、`slideToggle()`
- **自定义**：`animate()`
- **重点**：`stop()`：停止动画，防止动画叠加、抖动

### 5. AJAX 请求（必背）
```js
$.ajax({
  url: '',
  type: 'GET/POST',
  data: {},
  dataType: 'json',
  success: function(res){},
  error: function(err){},
  complete: function(){}
})
```
- **简写**：`$.get()`、`$.post()`、`$.getJSON()`
- **重点**：统一处理请求、响应、异常

### 6. 插件机制（重点）
- **全局插件**：`$.extend({ 方法 })`
- **元素插件**：`$.fn.extend({ 方法 })`
- **作用**：扩展功能、组件复用、封装业务
- **原理**：原型继承，挂载到 jQuery 原型

## 二、jQuery 后台管理系统 实战模式（必背）

### 1. 通用业务模式
- **表格渲染**：遍历数据 + 拼接 HTML
- **表单操作**：`serialize()` 序列化、提交、重置
- **弹窗交互**：新增、编辑、删除、确认
- **搜索筛选**：多条件查询、刷新列表
- **分页**：页码切换、数据加载
- **批量操作**：批量删除、批量状态修改

### 2. 常用组件
- 选项卡、折叠面板、树形菜单
- 表单校验、日期选择、下拉框
- 上传、导出、打印

### 3. 开发特点
- 快速开发、DOM 操作简单
- 适合后台系统、传统项目
- 兼容低版本浏览器

## 三、原生 JS 自定义框架封装（进阶重点）

### 1. 事件总线（发布/订阅模式）【必背】
- **核心方法**：`on` 订阅、`emit` 发布、`off` 取消
- **作用**：跨组件/跨模块通信、解耦
- **用途**：全局消息通知、状态同步

### 2. 模板渲染
- 模板字符串 + 数据拼接
- 数据驱动视图
- **原理**：`innerHTML` 渲染、数据与视图分离

### 3. 组件化雏形
- 一个组件 = HTML 结构 + CSS 样式 + JS 逻辑
- 可复用、可维护、独立作用域
- **组件生命周期**：创建 → 渲染 → 更新 → 销毁

### 4. 工具函数库（基础核心）
- 类型判断、深拷贝、防抖节流
- 时间格式化、存储、正则、DOM 操作
- 请求封装、异常处理、工具方法
- **作用**：减少重复代码、提高效率

## 四、框架封装分层思想（高级必背）

### 1. 基础工具层（底层）
- 纯工具、无业务、无依赖
- 深拷贝、防抖节流、类型判断、存储、正则
- 全项目通用、跨项目复用

### 2. 中级组件层（通用）
- 弹窗、表格、表单、选项卡、轮播、树
- 可复用 UI 组件
- 不依赖业务、可独立使用

### 3. 高级业务框架层（业务）
- 路由、请求、权限、状态管理、全局配置
- 面向业务、统一规范
- 快速开发后台系统

## 五、高频面试题（全必背）

### 1. jQuery 相关面试题

#### 1.1 jQuery 事件委托原理及优点？
**答：**
- **原理**：利用事件冒泡机制，将事件绑定在**父元素**上，由父元素统一监听子元素触发的事件。
- **优点**：
  1. 动态创建的元素也能绑定事件
  2. 只绑定一次，减少内存占用
  3. 性能更高，代码更简洁

#### 1.2 on / bind / live / delegate 区别？
**答：**
- **bind**：直接绑定元素，不支持动态元素
- **live**：事件委托，已废弃
- **delegate**：指定父元素委托，废弃
- **on**：**jQuery 推荐唯一绑定方式**，支持普通绑定 + 事件委托，统一用法

#### 1.3 jQuery AJAX 常用配置项？
**答：**
`url`、`type`、`data`、`dataType`、`success`、`error`、`complete`、`timeout`、`async`

#### 1.4 attr 和 prop 区别？
**答：**
- **attr**：操作 HTML 自定义属性、固有属性
- **prop**：操作 DOM 元素自带属性（checked、selected、disabled）
- **重点**：表单布尔状态必须用 prop

#### 1.5 jQuery 插件编写方式及原理？
**答：**
- **编写**：
  1. 全局插件：`$.extend({ fn(){} })`
  2. 元素插件：`$.fn.extend({ fn(){} })`
- **原理**：
  利用原型继承，将方法挂载到 jQuery 原型上，所有实例对象均可调用。

#### 1.6 $(this) 和 this 区别？
**答：**
- **this**：原生 DOM 对象
- **$(this)**：jQuery 包装对象，可以调用 jQuery 方法

#### 1.7 如何解决 jQuery 动画叠加？
**答：**
在动画前加 `stop()`，清除上一次未执行完的动画队列。

### 2. 原生框架 / 封装 相关面试题

#### 2.1 什么是事件总线？作用是什么？
**答：**
事件总线是**发布订阅模式**，包含 `on`(订阅)、`emit`(发布)、`off`(取消)。
**作用**：实现跨组件、跨模块通信，解耦代码。

#### 2.2 为什么要给框架分层？
**答：**
1. 职责清晰，便于维护
2. 复用性强，工具和组件可跨项目使用
3. 便于扩展、升级、替换
4. 降低耦合，提高开发效率

#### 2.3 框架三层封装分别是什么？
**答：**
1. **基础工具层**：深拷贝、防抖节流、类型判断、存储、正则
2. **中级组件层**：弹窗、表格、表单、树、选项卡
3. **高级业务层**：路由、请求、权限、全局状态、配置

#### 2.4 原生实现组件化的核心思路？
**答：**
一个组件 = 结构(HTML) + 样式(CSS) + 逻辑(JS)
**特点**：独立作用域、可复用、数据与视图分离、生命周期管理。

#### 2.5 原生如何做模板渲染？
**答：**
使用模板字符串拼接数据 → 生成 HTML → 插入 DOM 渲染视图。
即：数据驱动视图。

#### 2.6 你封装过哪些工具函数？
**答：**
深拷贝、防抖、节流、时间格式化、本地存储、AJAX 封装、正则校验、类型判断。

## 六、学习价值

- 帮助理解链式调用、插件化、DOM 批处理等思路
- 有助于从"会用框架"过渡到"知道框架为什么这样设计"

## 七、常见问题

- 把 jQuery 当成过时技术直接跳过，错过很多框架抽象基础
- 封装时只有工具函数，没有形成模块边界和职责分层

## 八、学习路线

1. 先理解 jQuery 如何简化 DOM、事件和 AJAX。
2. 再分析插件化和链式调用背后的抽象思路。
3. 最后尝试自己封装一套轻量工具层或组件层。
