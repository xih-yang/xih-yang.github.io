### Spring Boot 3.x中引入了哪些新特性？

**2、对GraalVM的原生编译支持：** Spring Boot 3.x提高了对GraalVM的支持，使得应用程序可以被编译成本地机器代码，从而减少内存占用和提高启动速度。

Spring Boot 3.x通过引入这些新特性，显著提升了应用程序的开发效率、运行性能和易维护性。
